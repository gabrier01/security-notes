A conversa com o cliente é uma das etapas para a realização de um serviço de [[7. Pentest]]. Nesta etapa, o profissional explica o seu trabalho e coleta o máximo de informações do cliente para entender o objetivo deste. Entre as informações importantes, estão:
- se é para cumprir alguma compliance/norma/certificação
- quais as preocupações do cliente (vazamento de dados de pessoais, vazamentos de segredos industriais etc)
- se existem sistemas críticos que devem-se tomar cuidado
- o que o cliente considera como um teste de sucesso
- quais as restrições do pentester (serviços que não podem ser acessados, tipos de ataques que não devem ser feitos ([[7. Engenharia Social]], [[7. Denial of Service|ddos]] etc))
- qual a deadline e horários de atuação (entender até que data o pentest será feito e se deve ser feito só dentro de um horário específico)
- contato direto com o cliente para informações ou resolução de dúvidas

Entendendo a necessidade do cliente, é possível determinar qual modalidade de teste deve ser feita, por exemplo, um Pentest [[7. Black Box|Blackbox]] Externo (abordagem ampla), Pentest Web [[7. Grey Box|Greybox]] (abordagem específica).
