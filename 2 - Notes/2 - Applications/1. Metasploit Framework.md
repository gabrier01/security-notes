Metasploit  Framework é uma plataforma de segurança ofensiva que reúne uma série de ferramentas para scanning de hosts, geração de payloads dinâmicos, detecção e exploração de vulnerabilidades, pós-exploração etc. A interface mais comum para interagir com o framework é o [[1. msfconsole]].

# Módulos

Um módulo do Metasploit é um pedaço de código (script) que realiza uma determinada atividade ofensiva dentro do framework. Os módulos possuem tipos diferentes que definem seu propósito no processo de scanning, exploração, entrega de payloads e pós-exploração etc, permitindo que cada etapa do ataque seja tratada de especializada. 

Como o framework possui arquitetura modular, é possível combinar cada uma dessas atividades para constituir um ataque. Por exemplo, podemos utilizar um determinado módulo de exploit, criar um payload específico para o host alvo, e, se a invasão for bem sucedida, executar um módulo específico de pós-exploração.

## Tipos de módulos

O tipo de um módulo determina a sua posição num processo de ataque. O nome de um módulo, que contém o seu tipo, segue uma árvore de especificidade, como se fosse um caminho para um arquivo numa árvore de diretórios.

Os tipos de módulos são os apresentados abaixo.
### Auxiliary

Módulos `auxiliary` agrupam o conjunto de tarefas que **não** são voltadas para exploração, mas sim coleta de dados, quebra de senhas, scanning, operações administrativas e até DoS para derrubada de serviços. 

**Exemplo:** `auxiliary/scanner/smb/smb_versions`

### Encoder

Módulos `encoder` são focado em codificação de bytes dado algum algoritmo de codificação. São úteis para ofuscar payloads e codificar "bad characters", como `null bytes`.

### Evasion

Módulos `evasion` são usados para modificar payloads e executáveis com objetivo de evadir sistemas de segurança como anti virus e EDR (Endpoint Detection and Response).

### Exploit

Módulo `exploit` agrupam os scripts voltados para se aproveitar de vulnerabilidades e executar código arbitrário ([[#Módulos#Tipos de módulos#Payload|payload]]).

Geralmente quando um exploit é executado com sucesso, é aberta uma [[#Seção]].

### NOP (No Operation)

Módulos `nop` são responsáveis por gerar uma sequência de instruções `nop` para alinhamento de bytes de um payload. Comumente usado em payloads para exploits de buffer overflow.

### Payload

Módulos `payload` (ver [[7. Payload]]) encapsulam o código arbitrário que será executado numa exploração de vulnerabilidade bem sucedida. Esses payloads podem ser construídos dinamicamente de forma que fiquem o mais específico para o cenário em que o atacante se encontra.

### Post

Módulos `post` são usados na etapa de pós-exploração, ou seja, quando o host alvo já está comprometido devido a exploração bem sucedida de uma vulnerabilidade.
