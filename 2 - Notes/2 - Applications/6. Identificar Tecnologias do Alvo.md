# Aplicações Web

Identificar tecnologias que uma aplicação web utiliza, isto é, web servers, sistemas operacionais, linguagens de programação, frameworks etc, é um processo bastante importante para refinar ainda mais a superfície de ataque e orientar a exploração de vulnerabilidades. Essas informações podem ser coletadas através de:
- Cabeçalhos de resposta [[5. HTTP]]
- Código fonte da página
- Mensagens de erro de páginas inexistentes (experimentar várias extensões de arquivos, especialmente as reconhecidas pelo tipo de webserver)
- Cookies
- Paths comuns dependendo do tipo de webserver

Esse tipo de interação pode ser facilitado com o uso de algumas ferramentas, listadas a seguir.
## whatweb

A ferramenta [[1. whatweb]] é capaz de identificar tecnologias utilizadas por páginas web:
```shell
$ whatweb example.com/some/page
```

## Weppalyzer

[[1. weppalyzer (extension)|Weppalyzer]] é uma extensão de navegador que analisa requisições HTTP e o conteúdo carregado nas páginas web para identificar automaticamente as tecnologias utilizadas.
