# Importância

Identificar tecnologias do alvo é uma etapa de extrema importância, pois nos ajuda a refinar a superfície de ataque e orientar a exploração de vulnerabilidades. Por exemplo, ao descobrirmos o tipo do serviço e sua versão, podemos buscar por [[7. Exploit|exploits]] conhecidos causados por bugs, má configuração etc.

# Ferramentas de uso geral

Ferramentas que podem automatizar o processo de enumeração e que não possuem um escopo específico, podendo ser utilizadas para diversos tipos de serviços e situações.
## nmap

A ferramenta [[1. nmap]] permite fazer varredura de portas e hosts. Dependendo dos parâmetros utilizados em sua execução é capaz de identificar sistema operacional, fazer [[7. Banner Grabbing|banner grabbing]] para identificar serviços e versões, identificar métodos de autenticação etc.

## ncat

A ferramenta [[1. ncat]] permite a interação direta com serviços de um host alvo. Pode ser usada para testar conexões, fazer [[7. Banner Grabbing|banner grabbing]] e até enviar payload mais especializados.

# Escopo
## Aplicações Web

Ao analisar uma aplicação web, é provável que consigamos identificar o tipo do web server, versão, sistemas operacionais, linguagem de programação, frameworks e demais tecnologias. Essa informações podem ser coletadas de:

- Cabeçalhos de resposta [[5. HTTP]]
- Código fonte da página
- Mensagens de erro de páginas inexistentes (experimentar várias extensões de arquivos, especialmente as reconhecidas pelo tipo de webserver)
- Cookies
- Paths comuns dependendo do tipo de webserver

### Requisição com método `HEAD`

Executar o método `HEAD` em algum `path` da aplicação faz com que apenas o cabeçalho seja retornado. Isso é bastante útil para termos uma visualização limpa dos campos de cabeçalho, que podem conter informações como sistema operacional, tipo do webserver, versão etc.

### whatweb

A ferramenta [[1. whatweb]] é capaz de identificar tecnologias utilizadas por páginas web:
```shell
$ whatweb example.com/some/page
```

### Weppalyzer

[[1. weppalyzer (extension)|Weppalyzer]] é uma extensão de navegador que analisa requisições HTTP e o conteúdo carregado nas páginas web para identificar automaticamente as tecnologias utilizadas.

## FTP

Serviços [[5. FTP]] são utilizados para transferência de arquivos, seja para realizar deploy de aplicações web, distribuição de binários ou arquivos públicos, backups, envio de documentos etc. Tendo isso em mente, dependendo do uso, identificar a tecnologia no serviço FTP ou até mesmo conseguir conectar a ele pode revelar uma série de informações.

### Banner Grabbing FTP

É muito comum que serviços FTP retornem um banner assim que nos conectarmos a ele. A conexão pode ser feita de várias formas, seja com [[1. ncat]] ou um client ftp específico:

```shell
$ ncat -v 172.16.1.50 21
# ou
$ ftp 172.16.1.50
```

Exemplo de retorno:

```
220 ProFTPD 1.3.5 Server (Debian)
```

Acima já teríamos a informação do tipo de servidor FTP (ProFTPD) e sua versão (`1.3.5`).

### Login anônimo

Alguns serviços FTP permitem logar de forma anônima, usando as seguintes combinações de usuário e senha: `anonymous:anonymous` ou `ftp:ftp`. Quando isso é possível, geralmente o servidor exibe uma mensagem logo após informar o username:

```
331 Anonymous login ok, send your complete email address as your password
```

Com acesso ao serviço, podemos então executar comandos, como o `help` para visualizar todos os comandos disponíveis, e tentar adquirir mais informações. Algo interessante que pode ser feito é entrar no [[5. FTP#Modo passivo|modo passivo]] e tentar navegar e listar diretórios.

## SMB

Serviços [[5. SMB]] são usados para que [[5. Host|hosts]] numa rede compartilhem recursos entre si. Esses recursos podem ser arquivos/diretórios, impressoras, IPC, outros dispositivos (termômetros, bombas de gasolina) etc.

Esse tipo de serviço é um excelente vetor de ataque a ser explorado, pois com ele é possível buscar por arquivos sensíveis e a execução de comandos remotos, que podem expor informações como usuários, políticas de senhas, etc.

### smbclient

Cliente SMB para interagir com recursos compartilhados. Permite apenas a interação com arquivos, diretórios e impressoras. Mais detalhes em [[1. smbclient]].

### rpcclient

Cliente SMB para interagir remotamente com o host alvo. Permite a execução de comandos que podem revelar informações extremamente importantes. Mais detalhes em [[1. rpcclient]].

### enum4linux

Ferramenta que automatiza o processo de enumeração de serviços SMB. Faz tudo o que `smbclient` e `rpclient` fazem. Mais detalhes em [[1. enum4linux]].

### Scripts do nmap

O [[1. nmap]] possui uma variedade de scripts voltados à enumeração SMB através de seu Scripting Engine (NSE). Todos os scripts voltados à serviços SMB podem ser encontrados no diretório `/usr/share/nmap/scripts/smb`.

Exemplo de uso:

```shell
$ nmap -v -p 139,445 --script=smb-os-discovery [IP]
```
