# Identificar métodos disponíveis

Ao identificar os métodos [[5. HTTP|HTTP]] suportados pela aplicação, conseguimos deduzir algumas das operações que podem ser realizadas. Em casos de [[7. API]] REST a aplicação faz uso idiomático e semântico dos métodos, refletindo exatamente o que pode ser feito por eles.

Em algumas situações, isso pode ser consultado através de uma requisição para `/<path>` utilizando o método `OPTIONS`:

```http
OPTIONS /some/path HTTP/1.0\r\n
\r\n
```

# Brute force em Páginas Web

Consiste em identificar, via tentativa e erro, caminhos válidos em uma página web, isto é, `paths` que retornam sucesso (`2xx`) ao serem requisitados.

## Script com [[1. curl]]

Consiste em usar uma `wordlist` de diretórios ou arquivos e testar acessar o conteúdo. Exemplo utilizando laço de repetição + [[1.curl]]:

```shell
#!/bin/zsh
# Usage: ./script domain.com wordlist.txt

domain=$1
wordlist=$2

for path in $(cat $wordlist); do
        http_code=$(curl -H "User-Agent: ReconScript" -s -o /dev/null -w "%{http_code}" "$domain/$path")
        if [[ $http_code == "200" ]]; then
                echo "[OK] $domain/$path"
        fi
done
```

Exemplo de wordlist pública no github [awesome_wordlists](https://github.com/gmelodie/awesome-wordlists) ([fork](https://github.com/gabrier01/awesome-wordlists))

## [[1. dirb]]

`dirb` é uma ferramenta de força bruta que automatiza a descoberta de diretórios e arquivos em servidores web. Utiliza uma wordlist contendo nomes comuns e envia requisições HTTP para identificar quais caminhos existem ou estão acessíveis.

# Ferramentas OSINT
## Google Hacking

É possível buscar por arquivos indexados na web com a seguinte dork:

```
site:domain.com ext:file-extension
```

Isso irá retornar todas as páginas de `domain.com` que possuem a extensão `file-extension`. Obviamente isso só funciona caso as páginas estejam indexadas pelo motor de busca.

É possível automatizar esse processo escrevendo um script usando [[1. lynx]] e filtrando seu retorno.
