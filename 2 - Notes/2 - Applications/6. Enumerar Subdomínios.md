Reconhecer subdomínios é uma forma de expandir a superfície de ataque. Existem múltiplas formas de fazer isso.

# Busca reversa por IP

Após [[6. Enumerar IPs do Alvo]], uma boa tentativa para descobrir subdomínios é fazer uma [[6. Resolução Reversa de DNS]], isto é, resolver um domínio a partir de seu [[5. IP (Address)|IP]].

# Transferência de Zona

Após descobrir os [[5. DNS Name Server|Name Servers Autoritativos]] de um domínio, é possível tentar realizar [[5. Transferência de Zona]]. Caso algum **Name Server** esteja mal configurado será possível adquirir o [[5. Zone File]], contendo todos os **Resource Records** do domínio.

> [!info] Identificar **NS** 
> Os **Name Servers Autoritativos** de um domínio podem ser facilmente identificados com  [[1. dig]]:
> 
> ```shell
> $ dig +short domain.com NS
> ```

# Brute Force de Subdomínio

Consiste em usar uma `wordlist` de domínios e testar resolver os domínios. Por exemplo:

```shell
#!/bin/zsh
# Usage: ./script domain.com wordlist.txt

domain=$1
wordlist=$2

for subdomain in $(cat $wordlist); do
	dig +short $subdomain.$domain
done
```

Exemplo de wordlist pública no github [n0kovo subdomains](https://github.com/n0kovo/n0kovo_subdomains/tree/main) ([fork](https://github.com/gabrier01/n0kovo_subdomains))

# Ferramentas OSINT

## Google Hacking

A dork `site`(ver [[10. Google Hacking]]) também pode exibir subdomínios que foram indexados por motores de busca.

```
site:domain.com.br
```

## `dnsdumpster.com`

É um site que automatiza o processo de enumeração de IPs e identificação de subdomínios: [DNS Dumpster](http://dnsdumpster.com).

## Shodan e Censys

[[1. Shodan]] e [[1. Censys]] também são ferramentas capazes de identificar subdomínios.
