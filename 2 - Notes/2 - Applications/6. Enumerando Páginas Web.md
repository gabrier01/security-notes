# Brute force em Páginas Web

## Script com [[1. curl]]

Consiste em usar uma `wordlist` de diretórios ou arquivos e testar acessar o conteúdo. Exemplo utilizado faço de repetição + [[1.curl]]:

```shell
#!/bin/zsh
# Usage: ./script domain.com wordlist.txt

domain=$1
wordlist=$2

for path in $(cat $wordlist); do
        http_code=$(curl -H "User-Agent: ReconScript" -s -o /dev/null -w "%{http_code}" "$domain/$path")
        if [[ $http_code == "200" ]]; then
                echo "[OK] $domain/$path"
        fi
done
```

Exemplo de wordlist pública no github [awesome_wordlists](https://github.com/gmelodie/awesome-wordlists) ([fork](https://github.com/gabrier01/awesome-wordlists))

## Google Hacking

É possível buscar por arquivos indexados na web com a seguinte dork:

```
site:domain.com ext:file-extension
```

Isso irá retornar todas as páginas de `domain.com` que possuem a extensão `file-extension`. Obviamente isso só funciona caso as páginas estejam indexadas pelo motor de busca.

É possível automatizar esse processo escrevendo um script usando [[1. lynx]] e filtrando seu retorno.
