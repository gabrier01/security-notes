Passo a passo de como configurar rapidamente um serviço [[5. NFS]] para teste.
# Instalar daemon

```
$ sudo apt install nfs-kernel-server
```

Para garantir que o daemon esteja executando, rode:

```shell
$ service nfs-kernel-server start
```
# Exportar diretórios

Diretórios exportados são identificados no arquivo `/etc/exports`. Para exportar um diretório, basta incluir uma entrada neste arquivo:

```
/home/username *(rw,sync,no_root_squash)
```

Para aplicar e propagar as exportações, basta executar o comando abaixo:

```shell
$ exportfs -r
```

# Verificar exportações

Para verificar os diretórios exportados, basta executar o comando abaixo (isto inclusive pode ser feito a partir de outro host):

```shell
$ showmount -e [host]

# $ showmount -e 192.168.0.10
# Export list for 192.168.0.10:
# /home/username *
```

# Montar um diretório remoto

Em um outro host, é possível montar o diretório remoto para um diretório local existente com o comando [[1. mount]]:

```shell
# Caso o path local não exista, é necessário criá-lo com mkdir
$ mkdir [local_path]
$ mount -t nfs [host]:[remote_path] [local_path] 
```


> [!redteam] Diretórios exportados em modo read/write
> Diretórios exportados em modo **read/write (rw)** permitem não apenas a leitura, mas também a escrita de arquivos. Isso pode ser extremamente crítico dependendo do diretório exportado. Por exemplo, se a **home** de um usuário for exportada para a rede, um atacante pode alterar o arquivo `~/.ssh/authorized_keys` e inserir sua própria chave pública, obtendo acesso remoto ao host como aquele usuário via [[5. SSH]].

Com o diretório remoto montado localmente, você pode navegá-lo normalmente com `cd`, além de interagir com os arquivos.

```shell
$ cd [local_path]
$ ls -a
$ cat [some_file]
```

# "Desmontar" um diretório

Quando o diretório montado não for mais necessário, é possível desmontá-lo via [[1. umount]]:

```shell
$ umount [local_path]
```
