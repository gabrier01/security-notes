Utilitário para enviar **raw packets** [[5. TCP]] para um [[5. Host|Hosts]]. Com ele é possível testar regras de firewall, fazer port scan, [[1. traceroute]] usando diferentes protocolos etc.

```shell
$ hping3 -S -p 80 google.com
# -S: setar flag SYN do pacote
# -p: porta de destino
```

O exemplo de chamada acima tenta iniciar uma conexão (enviando flag `SYN`) para a porta `80` do host de destino.

> [!redteam] Construir pacotes TCP com flags variadas
> Como o `hping3`, por padrão, envia **raw packets** TCP, é possível especificar uma variedade de flags e testar tipos diferentes de scanning ([[9. nmap#Técnicas de Scan|nmap - Técnicas de Scan]] para mais detalhes). O exemplo abaixo faz um [[9. nmap#FIN, NULL e Xmas Scan|Xmas Scan]] num host qualquer:
> ```shell
> $ hping3 -FPU -p [port] [host]
> ```

> [!info] Outros tipos de pacotes
> `hping3` também é capaz de enviar outros tipos de pacotes especificando, por exemplo, as opções `--icmp` ou `--udp`. Obviamente, com esses pacotes não é possível especificar as flags TCP.
