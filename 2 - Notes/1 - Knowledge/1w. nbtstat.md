Ferramenta disponível em sistema Windows para mostrar informações de **[[5. NetBIOS|NetBIOS]] Names** do host local ou de hosts conectados na mesma rede, além de detalhar sessões ativas que utilizem **NetBIOS over TCP/IP**.

# Usos

## Listar nomes locais

Lista os **NetBIOS Names** registrados para o host local:

```cmd
> nbtstat -n
```

## Exibir cache do nomes remotos

Exibe a tabela de cache contendo os **NetBIOS Names** de hosts conectados na rede:

```cmd
> nbtstat -c
```

Essa tabela de cache pode ser limpa com o comando `nbtstat -R`

## Buscar nomes de hosts remotos

Com o `nbtstat` é possível buscar pela tabela de nomes de hosts remotos de duas formas: com o nome do host ou com seu endereço [[5. IP (Address)|IP]]:

```cmd
> nbtstat -a [NETBIOS_NAME]
# ou
> nbtstat -A [IP_ADDRESS]
```

Se a tabela de nomes retornada pelo host possuir um **NetBIOS Name** do tipo `[HOSTNAME] <20>`, é um indicativo de que há um serviço de compartilhamento de arquivos ativo.

> [!redteam] `nbtstat -A` para Enumeração NetBIOS
> O comando `nbtstat -A [IP_ADDRESS]` permite detectar máquinas com **NetBIOS over TCP/IP** habilitado. Essa enumeração pode revelar **NetBIOS Names** registrados e indícios de serviços ativos, como compartilhamento de arquivos via [[5. SMB]]. Hosts identificados podem ser explorados com comandos como `net view` (ver [[1w. net]]) para listar recursos acessíveis na rede.

## Listagem de sessões ativas

Para listar sessões ativas via NetBIOS, basta usar o comando:

```cmd
> nbtstat -S
```
