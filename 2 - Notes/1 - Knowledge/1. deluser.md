Em contrapartida ao [[1. adduser]], este utilitário é responsável por deletar usuários de um sistema.

```shell
$ deluser [username] --remove-home
```

O comando acima remove o usuário `username` do sistema e deleta seu diretório em `/home`.

Esse comando possui opções mais avançadas como: deletar usuário de sistema, deletar grupos, remover usuários de grupos etc. Tudo isso pode ser visto em `man deluser`

# Removendo usuário de um grupo

Se quiser remover um usuário de um grupo, basta fazer:

```shell
$ deluser username group
```
