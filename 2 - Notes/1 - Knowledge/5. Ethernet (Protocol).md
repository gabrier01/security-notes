É um protocolo que entende endereços físicos, ou seja [[5. MAC Address]]. Um pacote do protocolo ethernet é chamado de `frame ethernet`.

# Cabeçalho

| Campo       | Tamanho (bytes) | Descrição                                                                                                                        |
| ----------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Destino MAC | 6               | Endereço MAC do destinatário (ex: `01:F4:B3:A4:9C:D8`)                                                                           |
| Origem MAC  | 6               | Endereço MAC do remetente (ex: `2B:FF:C1:03:FF:3D`)                                                                              |
| EtherType   | 2               | Indica o protocolo do payload (ex: `0x0800` = [[5. IP (Address)\|IPv4]], `0x86DD` = IPv6, `0x0806` = [[5. ARP (Protocol)\|ARP]]) |
| Payload     | 46 a 1500       | Dados transportados. Geralmente outro pacote encapsulado (arp, ip etc)                                                           |
| FCS         | 4               | CRC para detecção de erros (feito pelo hardware)                                                                                 |

Um payload ethernet tem um limite de 1500 bytes. Por conta disso, é muito comum que os pacotes encapsulados dentro de um ethernet tenham que ser fragmentados. Um exemplo de fragmentação pode ser encontrado em [[5. IP (Protocol)#Fragmentação do pacote|IP - Fragmentação do pacote]].

> [!note] Campo FCS
> O campo FCS (Frame Check Sequence) **não** deve ser especificado nem se estiver construir um **raw packet** Ethernet, pois seu valor é calculado e preenchido exclusivamente pelo hardware. Ele é um mecanismo de detecção de erros, tipo um [[7. Checksum]]. Mais especificamente, o algoritmo utilizado é CRC.

> [!note] Tamanho mínimo de payload
> O padrão IEEE 802.3, que define a especificação do protocolo Ethernet, estabelece que o tamanho **mínimo** de payload para o protocolo é `46 bytes`, portanto o tamanho **mínimo** total de um protocolo Ethernet é `64 bytes` . Se o payload possuir menos que o mínimo, é necessário preenche-lo com padding (bytes `0x00`).
