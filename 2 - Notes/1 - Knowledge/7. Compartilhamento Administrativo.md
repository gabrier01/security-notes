**Compartilhamentos administrativos** são recursos [[5. SMB|SMB]] que o Windows cria e disponibiliza automaticamente, sem configuração manual. São **ocultos**: o cifrão (`$`) no final do nome faz com que não apareçam numa enumeração normal de compartilhamentos (ex: `smbclient -L`). Apenas contas com privilégio de **administrador local** no host conseguem acessá-los; um usuário comum recebe `ACCESS_DENIED`.

Os principais são:

| Compartilhamento | Aponta para | Uso |
| ---- | ---- | ---- |
| `ADMIN$` | `C:\Windows` (`%SystemRoot%`) | Administração remota do sistema |
| `C$`, `D$`... | Raiz da unidade (`C:\`, `D:\`) | Acesso ao disco inteiro |
| `IPC$` | Nenhum diretório | [[7. Named Pipe\|Named pipes]] / RPC |

# ADMIN$

O `ADMIN$` mapeia para o diretório de instalação do Windows (`C:\Windows`). Acessar `\\[host]\ADMIN$` equivale a acessar a pasta do sistema do host remoto.

> [!redteam] ADMIN$ escreve arquivos, mas não executa
> Como todo compartilhamento de disco, o `ADMIN$` oferece apenas operações de sistema de arquivos: listar, ler, escrever, deletar. Depositar um `.exe` dentro dele deixa o binário parado no disco; ele **não roda por conta própria**. A execução vem de outro canal, tipicamente o **[[7. Service Control Manager|Service Control Manager (SCM)]]**, acessado via RPC sobre [[7. Named Pipe|named pipes]] (que trafegam pelo `IPC$`, não pelo `ADMIN$`).

Ferramentas de movimentação lateral combinam os dois mecanismos. O PsExec, por exemplo:
1. usa o `ADMIN$` para copiar um binário para `C:\Windows`;
2. usa o SCM (via `IPC$`) para criar um serviço apontando para esse binário e iniciá-lo.

Quem executa é o SCM, não o compartilhamento.

# Por que importa

Acesso administrativo é o pré-requisito comum dos dois mecanismos: as mesmas credenciais de admin local que abrem o `ADMIN$` também autorizam falar com o SCM remoto. Na prática, escrever no `ADMIN$` costuma equivaler a [[7. Remote Code Execution|execução de código]] como administrador.

É esse nível de acesso que o [[11. nxc]] sinaliza com `(Pwn3d!)` ao testar credenciais no protocolo `smb`.
