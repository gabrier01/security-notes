Um **Autonomous System (AS)** é uma coleção de blocos de rede ([[5. Net Blocks]]) gerenciados, geralmente, por um mesmo administrador. Este administrador pode ser uma grande empresa, ISP, órgãos governamentais ou qualquer entidade que necessite de autonomia para gerenciar um número expressivo de endereços [[5. IP (Address)|IP]] públicos. Um único administrador pode gerenciar múltiplos **AS**es.

O administrador de um **AS** possui autonomia de roteamento sobre os endereços IP de seus blocos, ou seja, pode decidir de forma independente como e por onde seu tráfego entra e sai da internet global (algoritmos de roteamento). Além disso, ele anuncia via [[5. BGP]] a outros **AS**es que pacotes destinados a determinados prefixos IP devem ser roteados para ele.

# ASN

Um **AS** é identificado por um número único chamado **Autonomous System Number (ASN)**. A partir dele é possível consultar quem é o administrador e quais blocos de IP fazem parte do **AS**.

> [!redteam] ASN e `whois`
> Realizar uma chamada [[1. whois]] em um [[5. IP (Address)|IP]] que faça parte de um **AS** fará com que o comando retorne, em algum campo, o **ASN** respectivo. Realizar uma outra chamada `whois` neste **ASN** retornará uma lista de blocos de rede geridos pelo **Autonomous System**, contudo essa lista pode não contemplar dados completos. Uma forma mais confiável de ver a lista de blocos de rede geridos pelo **AS** é acessar algum site que cataloga [[5. BGP]], como o https://bgp.he.net. 
> 
> Saber os blocos de rede de um alvo é uma informação é importante para aumentar seu **attack surface**.
