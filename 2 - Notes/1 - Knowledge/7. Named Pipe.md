Um **Named Pipe** é um recurso do sistema operacional usado para que processos se comuniquem entre si. É um dos meios possíveis de realizar **Inter Process Communication (IPC)**. Funciona como uma [[7. Stream|stream]], em que uma ponta escreve dados enquanto a outra lê. Em sistemas **Unix-like** geralmente são unidirecionais, funcionando como uma FIFO, já em sistemas Windows podem ser bidirecionais.

Um **named pipe** possui um nome único dentro do namespace em que for criado. Este nome é seu identificador, portanto, processos que queiram se comunicar devem se conectar à esse pipe através de seu nome.

# Named Pipes

Named Pipes geralmente são utilizadas para que processos dentro de um mesmo [[5. Host]] se comuniquem. Contudo, uma de suas aplicabilidades é permitir que um serviço exposto na rede se comunique com serviços locais do host, permitindo a realização de **Remote Procedure Calls (RPC)**.

Desta forma, uma RPC consiste na execução de uma operação remota entre cliente e servidor, sendo o servidor uma espécie de gateway que interpreta as requisições recebidas e as encaminha para os serviços locais correspondentes, devolvendo a resposta para o cliente.
