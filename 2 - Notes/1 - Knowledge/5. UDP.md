**User Datagram Protocol** é um protocolo da camada de transporte não orientado a conexão. Estrutura do cabeçalho UDP:

| Campo                | Tamanho | Função                                                                                                                                  |
| -------------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **Source Port**      | 16 bits | Porta UDP de origem (opcional: se for zero, indica que não está especificada).                                                          |
| **Destination Port** | 16 bits | Porta UDP de destino.                                                                                                                   |
| **Length**           | 16 bits | Tamanho **total** do datagrama UDP (cabeçalho + dados), mínimo = 8.                                                                     |
| **Checksum**         | 16 bits | Verificação de integridade do cabeçalho + dados + pseudo‑header IP (obrigatório em IPv6, opcional em IPv4; valor 0 desabilita em IPv4). |
Este protocolo basicamente define a porta de origem, porta de destino e o payload contendo os dados. O cliente que envia um pacote UDP **não** sabe se o servidor recebeu este pacote com sucesso, pois -- diferente do [[5. TCP]] -- ele não é orientado à conexão.

Esse tipo de protocolo geralmente é utilizado para serviços de streaming, em que o tráfego precisa ser rápido e a perda de pacotes é tolerável.
