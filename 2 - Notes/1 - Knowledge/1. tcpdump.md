Ferramenta de linha de comando para capturar pacotes da rede.

```shell
$ tcpdump -vn -i etho0 "icmp"
# -v: ativa modo verboso
# -i <net-interface>: define a interface de rede a ser monitorada 
# -n: não o IP puro por não tentar traduzi-lo para um hostname
# -e: traz detalhes sobre o protocolo Ethernet
# -A: imprime os pacotes em ASCII. Bom para interpretar pacotes que transferem dados via texto (HTTP, FTP etc).
# -X: imprime os pacotes em Hexadecimal
```

Os últimos parâmetros são os `pcap filters`, por exemplo `"tcp port 80"` (captura apenas pacotes `tcp` na porta `80`), `"host 192.168.0.9"` (captura apenas pacotes com host `192.168.0.9`), `"dst host example.com and tcp port 80"` etc. 

É possível também salvar o resultado num arquivo, para leitura posterior:

```shell
$ tcpdump -v -i etho0 "icmp" -w icmp.pcap
# -w <file>: arquivo de saída

$ tcpdump -r icmp.pcap
# -r <file>: especifica arquivo para ser lido
```

Ao ler o arquivo, é possível usar as mesmas flags usadas no primeiro exemplo.

## Filtros pcap úteis

- `tcp` ou `udp` ou `icmp` etc: filtra o protocolo do pacote.
- `tcp[tcpflags] & tcp-fin > 0`: realiza uma operação de bitwise para filtrar pacotes [[5. TCP|TCP]] que possuem a flag específica. Note que `tcpflags` é apenas um **alias** para o offset `13`, portanto, `tcp[13]` tem o mesmo significado que  `tcp[tcpflags]`. Exemplos de flags: 
	- `tcp-fin`: bom para filtrar pacotes em que uma conexão TCP foi encerrada, portanto, houve conexão bem sucedida
	- `tcp-ack`
	- `tcp-push`: bom para filtrar pacotes que houve envio de dados
	- `tcp-rst`
	- `tcp-syn`
	- `tcp-syn|tcp-ack`: boa combinação para filtrar por portas abertas em um servidor.
- `host <ip>`: filtra pacotes enviados ou recebidos por um [[5. IP (Address)|IP]].
	- `dst host <ip>`: apenas IP de destino do pacote
	- `src host <ip>` apenas IP de origem do pacote
- `port <number>`: filtra pacotes enviados ou recebidos por uma porta.
	- `dst port <number>`: apenas portas de destino do pacote
	- `src port <number`: apenas portas de origem do pacote
- `<protocol>[<offset>] <condition>`: permite criar filtros extremamente personalizados de acordo com o valor contido no byte a partir de `offset` do protocolo especificado. Por exemplo: `icmp[0] = 0` compara o primeiro byte de um pacote [[5. ICMP]] com o valor `0`; em outras palavras, filtra pacotes `Echo Reply`.

Os filtros acima podem ser combinados com os operadores lógicos `and` e `or` para criarem filtros mais complexos. Por exemplo: `tcp and tcp[tcpflags] = (tcp-syn|tcp-ack) and src host 192.99.100.4 and (src port 21 or src port 22)`; filtra pacotes TCP com as flags `SYN/ACK` recebidos de `192.99.100.4` pelas portas `21` ou `22`.

> [!info] Mais filtros
> Para mais filtros ver `man pcap-filter`.
