Uma `DSL` (Digital Subscriber Line) é uma tecnologia que permite a transmissão de dados digitais através de linhas telefônicas (analógicas). Essa tecnologia permitiu a transmissão simultânea de dados de internet e telefonia pela mesma linha, utilizando frequências distintas, diferente do [[7. Dial Up]] (Internet Discada), que usava a mesma frequência para as duas coisas.
