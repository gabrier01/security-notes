**Internet Control Message Protocol** (ICMP) é um protocolo usado para diagnóstico da rede. Não é um protocolo de transporte de dados, mas sim para envio de mensagens de controle e relatório, como por exemplo, indicar se um host está disponível, indicar se uma porta está fechada etc.

> [!info] `ping` e ICMP
> O utilitário [[1. ping]] utiliza o protocolo ICMP para enviar pacotes do tipo `echo-request` para testar se um [[5. Host]] está disponível ou não.

# Cabeçalho

| Campo              | Tamanho  | Função                                                                                                                                                                                                            |
| ------------------ | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Type**           | 8 bits   | Indica a mensagem ICMP<br>`0 = Echo Reply`<br>`3 = Destination Unreachable`<br>`8 = Echo Request`<br>`11 = Time Exceeded` (TTL expirado)                                                                          |
| **Code**           | 8 bits   | Sub‑tipo que refina o significado do **Type**. Exemplo se `type=3`<br>`0 = network unreacheble`<br>`1 = host unreacheable`<br>`2 - protocol unreachable`<br>`3 = port unreacheable`<br>`4 - fragmentation needed` |
| **Checksum**       | 16 bits  | Soma de verificação do cabeçalho + dados ICMP usado para detectar corrupção                                                                                                                                       |
| **Rest of Header** | 32 bits  | Campo genérico cuja estrutura depende do **Type/Code**                                                                                                                                                            |
| **Data / Payload** | variável | Para mensagens de erro: cópia do cabeçalho IP original + 64 bytes de carga.<br>Para Echo/Timestamp/etc: dados opcionais do usuário.                                                                               |

> [!redteam] Enumeração de hosts
> Um uso ordinário de pacotes ICMP num cenário de pentest é para enumerar dispositivos conectados numa rede. Contudo, esse tipo de enumeração é bem manjado e regras de firewall costumam filtrar ICMP `echo-request` para hosts que não esperam receber esse tipo de pacote (geralmente servidores).

> [!blueteam] Filtre `echo-request`
> Se um dispositivo na sua rede não esperar receber `echo-request` pra nada, é uma boa prática incluir uma regra no [[5. Firewall]] que rejeite silenciosamente esse tipo de pacote. Exemplo com [[1. iptables]]:
> ```shell
> $ iptables -A INPUT -p icmp --icmp-type echo-request -j DROP
> ```
