O arquivo `/etc/hosts.deny` é usado pelo sistema Linux (via TCP Wrappers) para negar acesso a serviços de rede. Ele contém regras que especificam quais clientes (por IP, hostname ou rede) não podem se conectar a determinados serviços controlados por TCP Wrappers (como sshd, vsftpd, etc.).

Exemplo de linhas:

```sh
# nega(DENY) tentativas de conexão de 192.168.0.50 a qualquer serviço (ALL) 
ALL: 192.168.0.50 DENY

# nega(DENY) tentativas de conexão de 172.16.1.50 apenas para o serviço sshd
sshd: 172.16.1.50 DENY
```


> [!warning] Port scanning ainda são possíveis
> Mesmo que um host esteja no `hosts.deny`, o tipo de bloqueio não é a nível de recebimento de pacotes de rede, mas sim à nível de aplicações que usam **TCP Wrappers**. Portanto, se um host estiver bloqueado para acessar o serviço `sshd`, ele ainda consegue verificar se a porta está aberta, contudo, o serviço, através de **TCP Wrappers** decidirá se aceita ou não o acesso.
