O **Address Resolution Protocol** (ARP) é um protocolo utilizado para resolver o [[5. MAC Address]] de um dispositivo a partir de seu [[5. IP (Address)]].

Esse protocolo é dividido em dois tipos de operações: `ARP Request` e `ARP Reply`. O `ARP Request` é enviado para o endereço MAC de broadcast (`FF:FF:FF:FF:FF:FF`) para que todos os dispositivos da rede recebam o pacote. Contudo, apenas o dispositivo que seja o `IP` requisitado responde enviando seu `mac address` via `ARP Reply`.

# Estrutura do pacote

Estrutura de um pacote ARP:

| Campo                 | Tamanho (bytes) | Descrição do conteúdo                    |
| --------------------- | --------------- | ---------------------------------------- |
| Hardware Type (HTYPE) | 2               | Tipo da rede física. Ethernet = `0x0001` |
| Protocol Type (PTYPE) | 2               | Tipo de protocolo. IPv4 = `0x0800`       |
| Hardware Size (HLEN)  | 1               | Tamanho do endereço MAC (normalmente 6)  |
| Protocol Size (PLEN)  | 1               | Tamanho do endereço IP (normalmente 4)   |
| Opcode                | 2               | Tipo da mensagem: request = 1, reply = 2 |
| Sender MAC Address    | 6               | MAC de origem                            |
| Sender IP Address     | 4               | IP de origem                             |
| Target MAC Address    | 6               | MAC de destino (zero em ARP request)     |
| Target IP Address     | 4               | IP de destino                            |

# Tabela ARP

Cada [[5. Host]] mantém uma tabela chamada `arp cache`, que salva temporariamente as traduções de `ip -> mac`, isto é, salva a resposta de todos os `ARP Reply` recebidos. Note que um `ARP Reply` pode ser recebido de forma ativa (quando há um `ARP Request` respectivo) ou de forma passiva (um outro host envia para todos na rede seu endereço mac).

Essa tabela pode ser acessada com o comando [[1. arp (Command)|arp]].
