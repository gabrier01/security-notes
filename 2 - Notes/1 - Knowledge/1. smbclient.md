Cliente de linha de comando que faz parte do [[8. samba]] para interagir com serviços [[5. SMB]]. É capaz de enumerar, acessar e gerenciar recursos compartilhados por um host.

# Enumeração

Enumera/lista quais recursos um host compartilha na rede:

```shell
$ smbclient -L \\[IP ou HOSTNAME] -U [username]
```

Por de baixo dos panos, o comando acima realiza, através do protocolo SMB, uma **Remote Procedure Call (RPC)** do tipo `NetShareEnumAll` para o host alvo, solicitando que ele enumere e retorne todos os recursos compartilhados. Nem todo `username` possui permissão para fazer esse tipo de RPC, portanto é possível que a requisição falhe.

# Acessar recurso compartilhado

Se conecta a um recurso compartilhado pelo host, habilitando o modo interativo, em que é possível executar comandos, como listagem e download de arquivos (se for um diretório), envio de arquivos para impressora etc.

**Exemplo de pasta compartilhada:**
```shell
#            .- note que a barra mudou 
$ smbclient //[IP ou HOSTNAME]/[RESOURCE] -U [username]
smb: \> ls
smb: \> cd www/html
smb: \> more index.html # visualizar arquivo
smb: \> get index.html original-index.html # download
smb: \> put hacked-index.html # upload
smb: \> del index.html # delete
smb: \> rename hacked-index.html index.html # rename
```


**Exemplo de impressora compartilhada:**
```shell
$ smbclient //[IP ou HOSTNAME]/[RESOURCE] -U [username]
smb: \> print document.pdf
```

# Modo anônimo

Conexão via modo anônimo, seja por `null session` ou `guest user`. Estes modos podem ser usados com qualquer operação do `smbclient`, seja listagem ou acesso a um recurso.

## Null Session

Exemplo de listagem com null session:
```shell
$ smbclient -L \\[IP ou HOSTNAME] -N
# -N: no password
```
## Guest

Exemplo de listagem com guest user:
```shell
$ smbclient -L \\[IP ou HOSTNAME] -N -U [username]
```


# Servidores legados

Alguns servidores legados não sabem lidar com versões novas do protocolo SMB. Para isso, é necessário informar um parâmetro para o `smbclient` que o force a utilizar uma versão mais antiga:

```shell
$ smbclient -L \\[IP ou HOSTNAME] --option="client min protocol=NT1"
```

O exemplo acima, irá forçar o `smbclient` a usar a versão `SMB1` (também conhecida como `NT1`).
