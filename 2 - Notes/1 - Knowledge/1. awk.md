Utilitário para fazer parser de streams de texto. Por exemplo, o **csv** abaixo:

```csv
gabrier,/home/gabrier,2025-01-01
example,/home/example,2025-01-04
other,/home/other,2025-01-23
```

Com o `awk` é possível parsear o conteúdo do arquivo e pegar só uma determinada coluna:

```shell
$ awk -F , '{print $2}' file.txt
# -F <delimitador>: especifica o delimitador para separar as colunas
# {print $<number>}: instrução para imprimir na tela determinada coluna 
```

Exemplo mais elaborado:

```shell
$ awk -F , '{print "Nome: " $1 "\t| Home Dir: " $2 }' file.txt
```

# Outras funcionalidades

O `awk` oferece uma variedade de funcionalidades, dividir streams de texto é apenas uma delas. Para mais detalhes, veja `man awk`.
