São empresas que facilitam a venda e gerenciamento de domínios para usuários finais, enviando as informações necessárias para o [[5. Registry]] que controla o [[5. TLD]] do domínio alocado. As informações enviadas ao **Registry** dependem do tipo do **pedido**, que podem ser para **criar**, **atualizar**, **renovar** ou **transferir** domínios. Geralmente as informações constituem em:

- Nome do domínio
- Dados do titular/registrante
- Dados dos [[5. DNS Name Server]]s autoritativos
- Validade do período de registro
- etc

> [!NOTE] O que ele não é/faz
> Note que um **Registrar** **NÃO** é obrigado a armazenar os **DNS Resource Records (RRs)**, ou seja, não é obrigado a mapear o domínio para seus respectivos [[5. IP (Address)|IPs]], servidores de email ([[5. Mail Exchange]]), [[5. CNAME]]s etc. Isso é de responsabilidade dos [[5. DNS Name Server]]s autoritativos.
> 
> Contudo, existem **Registrars** que oferecem esse serviço.


## Recursos obrigatórios

Um **Registrar** precisa oferecer, obrigatoriamente, um conjunto básico de recursos:

| Recurso                                              | Descrição                                                                                       |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| **Registro de domínio**                              | Capacidade de registrar domínios novos, consultando disponibilidade com o Registry.             |
| **Renovação de domínio**                             | Oferecer meios para renovar domínios e evitar sua expiração.                                    |
| **Atualização de nameservers**                       | Permitir que o titular defina ou edite os **nameservers autoritativos** do domínio.             |
| **Atualização dos dados do registrante**             | Alterar nome, email, telefone, endereço e dados WHOIS associados ao domínio.                    |
| **Transferência de domínio (out/in)**                | Oferecer código de transferência (EPP/AuthCode) e aceitar transferências de entrada.            |
| **Exibição dos dados WHOIS ou RDAP**                 | Mostrar ao titular quais dados estão registrados no domínio (conforme regras de privacidade).   |
| **Suporte a bloqueio de domínio (domain lock)**      | Recurso para evitar transferências não autorizadas.                                             |
| **Notificação de renovação e expiração**             | Informar prazos para renovação (obrigatório pela ICANN, ex: aviso com 30 dias de antecedência). |
| **Painel de controle ou interface de gerenciamento** | Interface (web, API, ou outra) para o titular gerenciar essas informações básicas.              |
Esses recursos obrigatórios são descritos pela [[5. ICANN]], com base no [contrato RAA (Registrar Accreditation Agreement)](https://www.icann.org/en/contracted-parties/accredited-registrars/registrar-accreditation-agreement/2013-registrar-accreditation-agreement-17-09-2013-en).

## Recursos opcionais

Alguns **Registrar** também oferecem serviços extras, como:

| Recurso                                                              | Observação                                                           |
| -------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Painel para gerenciar DNS Resource Records (A, AAAA, CNAME, MX, etc) | Serviço adicional; só necessário permitir edição de **nameservers**. |
| Hospedagem de site                                                   | Serviço opcional (muitos registrars são também hosts).               |
| Certificados SSL                                                     | Opcional; muitos vendem como extra.                                  |
| Proteção WHOIS gratuita                                              | Nem todos oferecem; depende do TLD e da política da CA.              |
| Email personalizado                                                  | Email personalizado com o domínio comprado, exemplo `mail@xpto.com`  |
| Name server autoritativo                                             | Serviço DNS opcional, que armazena os **DNS Resource Records**       |
