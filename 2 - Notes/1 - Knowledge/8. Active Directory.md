Active Directory (AD) é um serviço de diretório da Microsoft que centraliza a autenticação e autorização de usuários, computadores e recursos numa rede corporativa Windows. É implementado como Active Directory Domain Services (AD DS) e executado em servidores chamados Domain Controllers (DCs).

O AD organiza os objetos do domínio (usuários, grupos, computadores, políticas) em uma estrutura hierárquica baseada no protocolo [[LDAP]] e utiliza o [[Kerberos]] como protocolo de autenticação padrão.

# Componentes principais

## Domain Controller (DC)

Servidor que hospeda o AD DS e responde por autenticação e autorização de todos os objetos do domínio. Armazena o banco de dados do diretório no arquivo [[2. NTDS.dit]].

## Domain

Unidade administrativa central do AD. Agrupa usuários, computadores e outros objetos sob uma política comum. É identificado por um nome DNS (ex: `empresa.local`).

## Forest e Tree

- **Tree**: conjunto de domínios que compartilham um namespace DNS contíguo e possuem relação de confiança entre si.
- **Forest**: conjunto de Trees com relação de confiança. É o limite de segurança mais alto do AD.

## Organizational Unit (OU)

Contêiner lógico dentro de um domínio, usado para organizar objetos e aplicar Group Policy Objects (GPOs) de forma granular.

## Group Policy Object (GPO)

Conjunto de configurações aplicadas a usuários e computadores dentro de um domínio ou OU. Controla desde configurações de segurança até scripts de logon.

## SYSVOL

Diretório compartilhado replicado entre todos os DCs, que armazena GPOs, scripts e outros dados de política do domínio. Acessível via SMB em `\\[domain]\SYSVOL`.

# Protocolos utilizados

| Protocolo | Porta    | Função                                  |
| --------- | -------- | --------------------------------------- |
| LDAP      | tcp/389  | Consulta e modificação do diretório     |
| LDAPS     | tcp/636  | LDAP sobre SSL/TLS                      |
| Kerberos  | tcp/88   | Autenticação                            |
| SMB       | tcp/445  | Replicação, SYSVOL, NETLOGON            |
| RPC       | tcp/135  | Comunicação entre DCs                   |
| GC        | tcp/3268 | Global Catalog (consulta multi-domínio) |
| GC SSL    | tcp/3269 | Global Catalog sobre SSL/TLS            |

# Banco de dados

Todos os objetos do domínio são armazenados no arquivo [[2. NTDS.dit]], localizado nos DCs em `%SystemRoot%\NTDS\ntds.dit`. Este arquivo contém os hashes NTLM de todos os usuários do domínio e é o principal alvo em ataques de pós-exploração.

> [!redteam] Alto valor em pós-exploração
> Comprometer um Domain Controller e extrair o [[2. NTDS.dit]] equivale a obter as credenciais de todos os usuários do domínio. Isso permite movimentação lateral irrestrita e persistência via técnicas como Pass-the-Hash e Golden Ticket.
