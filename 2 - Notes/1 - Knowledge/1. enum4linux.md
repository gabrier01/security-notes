Ferramenta utilizada para automatizar o processo de enumeração em serviços [[5. SMB]]. Basicamente é um wrapper de ferramentas do pacote samba ([[1. smbclient]], [[1. rpcclient]] etc).

```shell
$ enum4linux [options] [IP]
```

# Opções de enumeração

Alguns exemplos de enumeração que podem ser automatizadas com `enum4linux`. Mas detalhes podem ser encontrados na mensagem de ajuda: `enum4linux -h`.

## Enumerar usuários

```shell
$ enum4linux -U [IP]
```

## Enumerar compartilhamentos

```shell
$ enum4linux -S [IP]
```

## Enumerar políticas de senha

```shell
$ enum4linux -P [IP]
```

## Enumerar tudo

```shell
$ enum4linux -a [IP]
```

> [!warning] Processo demorado
> Enumerar tudo pode ser um processo bem demorado. É recomendável que seja feito em segundo plano, enquanto você realiza outras atividades.
