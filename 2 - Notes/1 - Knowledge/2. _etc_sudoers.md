É um arquivo de configuração que determina quais usuários e/ou grupos podem escalar privilégios utilizando-se do comando [[1. sudo]], além de definir quais comandos eles podem rodar com privilégios escalados.

Neste arquivo é onde está definido, por exemplo, as circunstâncias sob as quais o grupo  [[3. sudo (group)]] podem escalar. No caso, em qualquer circunstância:

```
# Allow members of group sudo to execute any command
%sudo    ALL=(ALL:ALL) ALL
```

Contudo, é possível dar permissões de `sudo` à um usuário específico, sem adicioná-lo ao grupo `sudo`. Isso permite ajustes finos, como por exemplo, especificar um comando específico que o usuário pode executar como privilégios escalados.

```
username    ALL=(ALL:ALL) /bin/cat
```

Neste caso, está dada a permissão ao usuário `username` executar o comando `/bin/cat` a partir de qualquer máquina (`ALL`) como se ele fosse qualquer usuário e qualquer grupo (`ALL:ALL`). Exemplos:

```sh
# su username

$ sudo cat /etc/passwd
# mesma coisa que 'sudo -u root -g root cat /etc/passwd'

$ sudo -u gabrier cat /etc/passwd
# assumindo que 'gabrier' seja um usuário com permissão para acessar /etc/passwd, o comando acima, executado por 'username', será executado utilizando as permissões de 'gabrier.

$ sudo -g somegroup cat /etc/passwd
# mesmo caso de cima, contudo o comando é executado sob o grupo 'somegroup'
```

Para fins de entendimento, essas são as configurações que superusuário [[root]] possui, ou seja, ele também pode escalar privilégios sob quaisquer circunstâncias:

```
# User privilege specification
root     ALL=(ALL:ALL) ALL
```

## Exemplos de configuração

1. `username` tem permissão para usar `sudo` apenas no comando `cat`, executando-o com suas próprias permissões. Na prática, essa configuração **não eleva privilégios**, pois o comando é executado como o próprio usuário. O principal efeito é restringir o uso do `sudo`  apenas para esse comando específico.
```
username ALL=(username:username) /bin/cat
```

2. `username` tem permissão para usar `sudo` em qualquer comando, podendo utilizar apenas as permissões do usuário `gabrier` em qualquer grupo.
```
username ALL=(gabrier:ALL) ALL
```

3. `username` tem permissão para usar `sudo` em qualquer comando, contudo tendo as mesmas permissões que o usuário `gabrier` no grupo `gabrier` possui.
```
username ALL=(gabrier:gabrier) ALL
```
