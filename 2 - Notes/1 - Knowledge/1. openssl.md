Utilitário que permite utilizar, via linha de comando, diversas funções de criptografia da biblioteca OpenSSL. Dentre essas funções, é possível: gerenciar chaves públicas e privadas, criação de certificados [[5. Certificado X.509|X.509]] auto assinados, criação de CSR, criptografia/descriptografia etc.

# Exemplos de uso

## Geração de chave privada e certificado X.509 autoassinado

```shell
$ openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem -days 365
# req: make a Certificate Signing Request
# -x509: create and autosign a x509 certificate. Use -new to create only a CSR file
# -newkey <algorithm>:<size>: to create a new key, rsa:2048 in this case
# -keyout <file>: file to store the generated rsa key
# -out <file>: file to store the x509 certificate or CSR file
# -days <number>: certificate expiration in days  
```

Essa chave e certificado gerados podem ser usados, por exemplo, em um listener do [[1. ncat#Habilitar criptografia SSL|ncat]] para  criptografar as conexões.

## Gerando CSR

O comando mostrado acima cria uma CSR (Certificate Signing Request) para um certificado **X.509**, contudo o **auto assina** em seguida, com a opção `-x509`. Um certificado auto assinado, mesmo possuindo uma chave pública válida, indicando que a conexão está criptografada, não garante a legitimidade da entidade emissora, para mais detalhes veja [[5. Certificado X.509#Certificados auto assinados|X.509 - Certificados auto assinados]].

Um certificado auto assinado muitas vezes é rejeitado pelo navegador ou sistemas. Para isso, é necessário gerar uma **CSR (Certificate Signing Request)** e enviar para uma Autoridade Certificadora, para que esta assine e te devolva um certificado **X.509** assinado. Isso pode ser feito com:

```shell
$ openssl req -new -newkey rsa:2048 -keyout key.pem -out req.csr
```

As únicas mudanças desse comando é o uso de `-new` ao invés de `-x509` e o arquivo de saída `-out req.csr`. O arquivo `req.csr` conterá a CSR contendo sua chave pública e informações sobre sua organização (nome, localização, email de contato etc).
