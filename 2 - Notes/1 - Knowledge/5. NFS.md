**Network File System** (NFS) é um protocolo da [[5. Camada de Aplicação]] de rede para compartilhamento de sistema de arquivos entre hosts Linux numa mesma rede. Serviços NFS, escutam, por padrão, na porta `tcp/2049`.

É um protocolo baseado em chamadas [[5. RPC]].

> [!redteam] Enumerar NFS
> Por se tratar de um protocolo que utiliza comunicação RPC, é possível enumerar serviços NFS de um host com o utilitário `rpcinfo`: [[1. rpcinfo|rpcinfo -p <host> | grep "nfs"]].

# Enumerar diretórios exportados

```shell
$ showmount -e [host]
```

# Montar um diretório exportado

```
$ mount -t nfs [host]:[remote_path] [local_path]
```
