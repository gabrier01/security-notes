Ferramenta para identificar o tipo de hash utilizado para encriptar algum dado. Muito comum para identificar hashes de senhas.

# Uso

```shell
$ hashid [hash] [options]
# -m, --mode: exibe output no formato do Hashcat
# -j, --john: exibe output no formato do JohnTheRipper (john)
```

Se nenhum `[hash]` for informado, a ferramenta fica esperando alguma entrada via `stdin`.
