É um protocolo da pilha `TCP/IP` específico para consultar informações de contato e [[5. DNS (Protocol)]] sobre um domínio, endereço IP ou [[7. ASN]]. Comumente serviços `WHOIS` executam na porta `43` de um [[5. Host]]. 

> [!info] Falta de padronização
> Infelizmente a [[7. RFC]] do `WHOIS` ([RFC 3912](https://www.rfc-editor.org/rfc/rfc3912.txt)) não define um padrão para o payload dos pacotes, apenas a forma de conexão (porta `43`, protocolo [[5. TCP]]). Contudo, há um outro protocolo que busca substituir o `WHOIS`: o [[5. RDAP]].

> [!tip]
> *Um comando útil para automatizar essas buscas é o [[1. whois]].*
## Payloads

O protocolo pode carregar dois tipos de payloads, que determinam a tipo de operação: `QUERY`e `ANSWER`.
### Query

É a operação feita para requisitar informações de uma entidade. Exemplo de formatos:

```
example.com.br\n\n
```

```
domain example.com.br\r\n
```


> [!info] Domain **Vs** IP
> Há diferença entre fazer uma busca por um domínio e busca por IP. Buscar o domínio irá trazer informações como nome do dono, empresa responsável pela venda do domínio, status etc. Buscar por IP traz informações como [[5. IANA#Net Number|net number]], [[5. IANA#ASN|ASN]] (opcional), empresa que controla o range de IP, contatos técnicos etc.
