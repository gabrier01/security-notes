O `samdump2` é um utilitário Linux usado para extrair hashes de senhas do arquivo [[2. SAM]] do Windows. Como o `SAM` possui uma camada extra de criptografia nos hashes, o `samdump2` utiliza o arquivo [[2. SYSTEM]] para obter a `syskey` e descriptografar os hashes.

# Uso

```shell
$ samdump2 [system-file] [sam-file]
```

- `[system-file]`: caminho para o arquivo `SYSTEM` (ou backup dele).
- `[sam-file]`: caminho para o arquivo `SAM` (ou backup dele).

## Exemplo

```shell
$ samdump2 SYSTEM.bak SAM.bak
```

A saída exibe os hashes no formato `usuario:rid:lm-hash:nt-hash`, por exemplo:

```
Administrator:500:aad3b435b51404eeaad3b435b51404ee:31d6cfe0d16ae931b73c59d7e0c089c0:::
```

Os hashes obtidos podem ser quebrados com ferramentas como [[1. john]] ou passados diretamente em ataques [[4. Pass The Hash]].
