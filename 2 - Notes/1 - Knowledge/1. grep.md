Utilitário responsável por filtrar stream de dados:

```shell
$ cat log.txt | grep "user connected"
# retorna apenas as linhas que contenham o texto "user connected"
```

```shell
$ cat log.txt | grep -E "(linux|windows)"
# filtra por regex, buscando qualquer ocorrência "linux" ou "windows"
```

# Opções

- `-v`: inverte o comportamento normal, ou seja, **não** retorna as linhas que seguem determinado padrão
- `-i`: torna a busca case-insensitive
- `-w`: busca por palavras, ou seja, `-w "lorem"` diferencia `"loremipsum"` de `"lorem ipsum"`
- `-x`: busca por linhas completas, ou seja, `-x "lorem ipsum"` só retorna linhas que são exatamente igual `"lorem ipsum"` 
- `-E`: interpreta o pattern como se fosse um **regex**. Útil para filtros mais complexos ([Regex Cheat Sheet](https://www.rexegg.com/regex-quickstart.php))
- `-r`: verifica recursivamente cada arquivo dentro de um diretório 
- `--include <file-pattern>`: filtra quais arquivos a verificação será feita (útil em conjunto com `-r`)
