O arquivo `SAM` (Security Account Manager) é um **arquivo loca**l em sistemas [[Windows]] que armazena nomes de usuários e hashes de senhas. É utilizado para validar o login de usuários e gerenciar quais grupos eles pertencem. O arquivo original comumente fica em `%SystemRoot%\System32\config\SAM`.

Possui uma camada extra de criptografia em cima dos hashes das senhas, portanto estes hashes não podem ser obtidos se você possuir apenas o arquivo `SAM`. Para descriptografá-los é necessário uma chave (`syskey`) que fica no arquivo [[2. SYSTEM]].

# Proteção

Por ter um conteúdo muito sensível, o Sistema Operacional obtém acesso exclusivo ao arquivo no momento em que o sistema é carregado, bloqueando qualquer outro acesso. Dessa forma, é impossível lê-lo, escrevê-lo ou até mesmo copiá-lo, pois alegará que o arquivo está em uso por outro processo.

# Burlando bloqueio

Há algumas formas de burlar o bloqueio imposto pelo sistema, sendo elas:
- **Acessar o dispositivo fisicamente:** é possível fazer boot com Live CD, acessar o sistema de arquivos sem carregar o windows e copiar o arquivo.
- **Acessar backup em `rapair`**: em sistemas mais antigos é possível acessar backups deste arquivo nos diretórios de [[2. repair]].
- **Recuperar dos registros do windows**: quando o Windows inicializa, o SAM é armazenado em um registry do sistema para acesso mais rápido. Com o comando [[11. reg]] é possível ler o conteúdo desses registries e salvá-los num arquivo. (`reg save HKLM\SAM SAM.bak`)
- **Montar uma cópia sombra ([[VSS]])**: tecnologia do Windows que permite criar snapshots consistentes de volumes em um ponto no tempo, possibilitando a cópia de arquivos mesmo enquanto estão em uso por outros processos.

# Descriptografar campos protegidos

Como dito, o campo contendo os hashes possuem uma camada de criptografia adicional, que impossibilita a visualização dos hashes. Contudo, com o arquivo [[2. SYSTEM]] em mãos, é possível descriptografar. Para isso, pode ser utilizado os utilitários [[11. samdump2]] ou [[1. impacket-secretsdump]].

```shell
$ samdump2 [system-file] [sam-file]
```

```shell
$ impacket-secretsdump -sam [sam-file] -system [system-file] LOCAL
```
