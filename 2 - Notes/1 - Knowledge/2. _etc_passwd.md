Arquivo que contém a listagem de todos os usuários criados no sistema.

```shell
$ cat /etc/passwd
# root:x:0:0:root:/root:/usr/bin/zsh
# daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
# bin:x:2:2:bin:/bin:/usr/sbin/nologin
```

Cada linha do arquivo é um usuário criado no sistema e elas seguem o seguinte formato:

```shell
<username>:<passwd>:<uid>:<gid>:<gecos>:<home-dir>:<command-or-shell>
```

- `username`: nome do usuário no sistema; usado para fazer o login.
- `passwd`: senha do usuário; em sistemas mais modernos terá o caractere `x`, indicando que a senha está salva no arquivo [[2. _etc_shadow|/etc/shadow]].
- `uid`: id do usuário.
- `gid`: id do grupo principal, conforme salvo em [[2. _etc_group|/etc/group]].
- `gecos`: informações sobre usuário; campo de texto livre para preencher informações como nome de usuário, número de telefone etc.
- `home-dir`: caminho absoluto para o diretório do usuário.
- `command-or-shell`: caminho absoluto para o binário de um comando ou shell; para usuários comuns tipicamente é um shell. O binário é executado assim que o login for efetuado com sucesso.

Originalmente este arquivo também continha os hashes de senha dos usuários, contudo, como este arquivo pode ser acessado por quaisquer usuários, os hashes de senhas foram movidos para o arquivo [[2. _etc_shadow|/etc/shadow]], que é acessível somente pelo usuário `root`.
