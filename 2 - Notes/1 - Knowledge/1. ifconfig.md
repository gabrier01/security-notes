> [!warning] Deprecated
> Atualmente o comando `ifconfig` é datado. Um comando mais moderno é o [[1. ip]].

Ferramenta para exibir e/ou configurar adaptadores de rede. O uso comum para este comando é listar os adaptadores de rede e ver os endereços [[5. IP (Address)|IP]].

```shell
$ ifconfig
```

Mas ele pode ser usado, também, para configurar um IP privado:

```shell
$ ifconfig eth0 192.168.0.99 netmask 255.255.255.0
```

Essa forma de configuração acima é temporário. Após a máquina ou interface de rede reiniciar, um novo IP privado será atribuído. Para atribuir um IP privado estático, é necessário configurar o arquivo [[2. _etc_network_interfaces|/etc/network/interfaces]].

> [!info] Informações sobre roteamento
> Ao usar o `ifconfig` para listar interfaces de rede e os IPs, ele **não** exibe o IP do [[5. gateway]], pois isso se trata de informações sobre **roteamento**. Para consultar informações sobre roteamento utilize o comando [[1. route]] ou [[1. ip|ip route]]
