Ferramenta para realizar [[5. DNS (Protocol)|DNS]] lookup de um host e retornar seus **Resource Records**. O tipo de consulta mais básico usando `host` é a seguinte, em que é tentado resolver os registros **A** e **AAAA** e **MX** de um domínio alvo:

```shell
$ host google.com
```

> [!info] Tipo de query
> É possível especificar o tipo de query a ser realizada, informando a opção `-t <QTYPE>`. Os valores de `QTYPE` podem ser encontrados em: [[5. DNS (Protocol)#2.1.1. Destrinchando o campo `QTYPE`|Destrinchando o campo QTYPE]].
