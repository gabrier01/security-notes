O usuário `root` é o superusuário padrão dos sistemas Linux, com privilégios elevados que permitem executar **qualquer ação no sistema**, sem restrições.

O motivo disso é que em sistemas Linux o usuário de uid 0 é o superusuário absoluto e, como mostrado logo abaixo, é o caso do `root`:

```shell
$ id root
# uid=0(root) gid=0(root) groups=0(root)
```
