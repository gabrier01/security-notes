É um super utilitário que possui diversos subcomandos para gerenciamento de rede e sistema.

```shell
> net user
# lista os usuários locais do sistema

> net user username
> # retorna informações sobre o usuário
```

```shell
> net view
# retorna os dispositivos visíveis conectados na mesma rede que possuem compartilhamento ativo

> explorer \\hostname
# tenta 
```
