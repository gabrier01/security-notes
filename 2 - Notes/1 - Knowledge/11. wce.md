O `wce.exe` (Windows Credentials Editor) é uma ferramenta de pós-exploração para Windows que extrai credenciais armazenadas em memória pelo processo **LSASS** (Local Security Authority Subsystem Service). Permite obter hashes NTLM e, em determinadas configurações, senhas em plaintext de usuários com sessão ativa.

É funcionalmente similar ao [[11. mimikatz]], porém mais antigo e com menos funcionalidades. **É Detectado pela maioria dos antivírus modernos**.

> [!redteam] Requer privilégios elevados
> Para acessar a memória do LSASS, o `wce.exe` requer privilégios de ****SYSTEM** ou Administrador local.

# Uso

```shell
wce.exe [options]
# -l Lista sessões de login ativas com seus hashes NTLM
# -e Lista sessões ao detectar novo logon
# -r Lista sessões continuamente (modo watch)
# -w Dump de senhas em plaintext (requer WDigest ativo)
# -s <hash> Injeta hash NTLM na sessão atual (Pass-the-Hash)
```
