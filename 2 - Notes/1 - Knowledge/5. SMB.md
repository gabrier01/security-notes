**Server Message Block (SMB)** é um protocolo da [[5. Camada de Aplicação]] usado principalmente para compartilhamento de recursos numa rede, como: arquivos e diretórios, impressoras, IPC (inter process communication) etc. É massivamente utilizado em sistemas Windows, contudo há suporte para sistemas Unix-like via [[8. samba]]. 

Atualmente, nas versões mais atualizadas do protocolo, serviços SMB escutam na porta `TCP/445`. Contudo, a versão legada (SMB1) escuta na porta `TCP/139`, pois utiliza como base o [[5. NetBIOS#NetBIOS sobre TCP/IP|NetBT]].

# Modos de conexão

O protocolo permite dois tipos de conexão: Autenticada e Anônima.

## Autenticado

É o modo de conexão que requer login válido, isto é, usuário e senha reconhecidos pelo sistema. É recomendado que seja o único modo de conexão disponível, pois evita as falhas de segurança que podem ser exploradas via [[#Anônimo|modo anônimo]].
## Anônimo

É o modo de conexão em que não há autenticação por parte do cliente. Este modo pode ser dividido em dois "submodos": **null session** e **guest**.

> [!redteam] Enumeração via modo anônimo
> Caso o servidor permite conexão anônima, seja por null session ou usuário guest, é possível que consigamos enumerar usuários, grupos e recursos compartilhados pelo host através de algum [[#Clientes SMB|cliente smb]]. Enumerar esses recursos é importante, pois eles podem expor informações sensíveis (em arquivos compartilhados), ou permitir escalar privilégios.

> [!blueteam] Desabilite conexões anônimas
> Permitir conexão anônima abre margem para um atacante enumerar os recursos compartilhados por um host conectado na mesma rede. É recomendável que seja desabilitado:
> 
> **Windows**:
> - Criar registro `RestrictNullSeeAccess = 1` em `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\LanmanServer\Parameters`
> - Isso pode ser feito também via interface gráfica, em `win+r "gpedit.msc" -> Configuração do Computador -> Modelos Administrativos -> Rede -> Estação de trabalho do LANMAN` e desabilitar a configuração `Habilitar logons de convidados não seguros`.
>   
> **Linux (com samba):**
> ```ini
> # /etc/samba/smb.conf
> [global]
> restrict anonymous = 2
> map to guest = Never
> 
> # Para cada recurso compartilhado
> [shared_resource]
> guest ok = no
> ```

### Null Session

Neste tipo de conexão anônima, o cliente se conecta sem especificar usuário e senha, ou seja, completamente anônimo.

## Guest

Neste tipo de conexão anônima, o cliente se conecta utilizando um username, contudo sem senha. Servidores configurados dessa forma, redirecionam o cliente conectado para o contexto **guest**, que pode ter menos privilégios que o usuário original, contudo ainda podendo enumerar recursos compartilhados pelo host.

# Tipos de recursos compartilhados

O protocolo SMB permite o compartilhamento de recursos variados na rede, entre eles: arquivos/diretórios, impressoras e interface `IPC` para execução de comandos remotos.

Cada tipo de recurso é identificado por um tipo, sendo os mais comuns:
- `STYPE_DISKTREE (0x00000000)`: disco; possibilita acesso à arquivos e diretórios
- `STYPE_PRINTQ (0x00000001)`: impressora
- `STYPE_DEVICE (0x00000002)`: dispositivo físico ou lógico; permite interação com um determinado dispositivo, seja ele um scanner, plotter
- `STYPE_IPC (0x00000003)`: IPC; possibilita execução de comandos de forma remota, utilizando [[7. Named Pipe|named pipes]].

## IPC e Named Pipes

No caso do `IPC`, cada named pipe é uma interface para realizar operações diferentes, geralmente relacionadas à serviços administrativos. As principais named pipes são:
- `\pipe\srvsvc`: **Server Service;** enumeração de compartilhamentos, sessões e impressoras
- `\pipe\samr`: **Security Account Manager**; gerenciamento de usuários, grupos e domínios
- `\pipe\lsarpc`: **Local Security Authority RPC**; políticas de segurança, direitos e auditoria
- `\pipe\netlogon`: **Netlogon Service**; autenticação, replicação e controle de domínio
- `\pipe\spoolss`: **Print Spooler Service**; gerenciamento de filas e trabalhos de impressão
- `\pipe\winreg`: **Registros do Windows**; acesso remoto aos registros do Windows
- `\pipe\browser`: **Browser Service**; navegação e listagem de recursos da rede
- `\pipe\sessmgr`: **Session Manager**; gerenciamento de sessões SMB

É possível interagir com algumas dessas named pipes via clientes RPC, como por exemplo o [[1. rpcclient]]. Para detalhes sobre os comandos disponíveis, ver [[1. rpcclient#Comandos|rpcclient - Comandos]].

# Clientes SMB

Alguns clientes para interagir com serviços SMB:

- [[1. smbclient]] para acessar recursos compartilhados que envolvem arquivos e diretórios. Funciona de uma jeito similar ao [[5. FTP]].
- [[1. rpcclient]] para realizar **Remote Procedure Calls (RPC)**
