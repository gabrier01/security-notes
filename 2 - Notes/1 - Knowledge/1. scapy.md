Ferramenta interativa, baseada em Python, para criação e manipulação de pacotes de rede. Opera em modo **REPL**(Read-Eval-Print Loop), permitindo a criação, modificação, envio, recepção, decodificação e análise de pacotes em tempo real. Suporta diversos protocolos das camadas 2 a 7 e oferece uma ampla gama de classes e funções para a construção de pacotes, sniffing, fuzzing, [[1. traceroute|traceroute]], fingerprinting etc.

```shell
# abre o modo interativo
$ scapy
```

# Introdução

## Listagem e ajuda com comandos

Após abrir o shell interativo do `scapy`, podemos listar todos os comandos suportados por ele com a função `lsc()`:

```python
>>> lsc()
```

Para mais detalhes sobre os comandos listados, podemos especificar o nome do comando como argumento para `help`:

```python
>>> help(sr)
```

## Protocolos suportados

Para listar todos os protocolos suportados pelo `scapy`, podemos utilizar a função `ls()`:

```python
>>> ls()
```

> [!info] Pacotes mais comuns
> A ferramenta suporta uma variedade de pacotes, inclusive os mais comuns, que estamos mais familiarizados, como `IP`, `TCP`, `UDP`, `ICMP`, `ARP` etc.

Para detalhes sobre um protocolo, pode-se passar o nome do protocolo como argumento para `ls`:

```python
>>> ls(IP)
```

A função acima, executada com a classe `IP`, irá retornar os parâmetros que representam o [[5. IP (Protocol)#Cabeçalho|cabeçalho do protocolo IP]].

> [!NOTE] Os pacotes são classes `python`
> Lembre-se que `scapy` é `REPL` rodando sob um `shell python`. Portanto, dentro desse ambiente, os protocolos como `IP`, `TCP`, `UDP` são representados por **classes Python**, e seus campos são **atributos dessas classes**. O comando `ls()` permite inspecionar essas classes, listando seus atributos e valores padrão.

# Exemplos práticos

## Construir e enviar um pacote TCP

Com o `scapy`, é perfeitamente possível construir um **raw packet** TCP e enviá-lo. Contudo, como um pacote TCP é encapsulado em um pacote IP, teremos que começar por este último:

```python
>>> pkt_ip = IP(dst="192.168.0.50")
```

> [!tip] Visualizar pacote
> Com os métodos `.show()` ou `.summary()`, é possível visualizar o pacote construído com seus parâmetros e valores. Exemplo: `pkt_ip.show()`.

Definido o host de destino no pacote IP, podemos definir o pacote TCP com a porta do serviço do destino:

```python
>>> pkt_tcp = TCP(dport=80, sport=RandShort())
```

> [!NOTE] Port de origem aleatória
> Por padrão, o `scapy` utiliza a porta 20(ftp_data) como porta de origem. Contudo, é possível gerar uma porta aleatória com a função `RandShort()` e passá-la para `sport`.


> [!tip] Múltiplas portas de destino
> É possível especificar uma lista em `dport`, exemplo `dport=[21, 22, 80, 443]`, fazendo com que o `scapy` envie múltiplos pacotes.


Com ambos pacotes montados, podemos criar o pacote final, concatenando `pkt_ip` e `pkt_tcp` com o operador `/` e enviá-lo com a função `sr1()`:

```python
>>> pkt_final = pkt_ip/pkt_tcp
>>> pkt_response = sr1(pkt_final)
```

Com base na descrição retornada por `help(sr1)`, a função `sr1` envia pacotes na camada 3 (IP) e espera apenas pela primeira resposta.

O `scapy` fica responsável por preencher algumas informações importantes sobre os pacotes, como `ttl`, `checksum`, `flags TCP`, `sequence number` etc, mas tudo isso pode ser modificado alterando os valores dos atributos, por exemplo `TCP(flags="A", ...)`, `IP(ttl=123, ...)` etc.


> [!info] Múltiplas respostas
> Em caso da espera de múltiplas respostas, por exemplo no caso de especificar múltiplas portas, a função adequada seria `sr()`.


## Concatenar payload personalizado

Se analisarmos o pacote enviado no exemplo acima em algum `sniffer`, como [[1. tcpdump]] ou [[1. wireshark]], notaremos que o pacote enviado não possui nenhum payload. Contudo, é possível especificar um payload personalizado e concatená-lo ao pacote final, como no exemplo abaixo:

```python
>>> payload = b"\xA1\xB2\xC3\xD4"
>>> pkt_final = pkt_ip/pkt_tcp/payload
>>> sr1(pkt_final)
```

No exemplo acima, criamos  uma sequência  binária `0xA1B2C3D4` e concatenamos ao final do pacote. O valor do payload poderia ser um texto também.

## Criação de scripts

Como o `scapy` funciona sob o shell interativo do python, é possível programar em python dentro dele. Por exemplo:

```python
>>> ips = ["192.168.0.50", "172.16.1.20", "1.1.1.1"]
>>> pkt_tcp = TCP(dport=[21, 22, 80, 443])
>>> for ip in ips:
>>> 	pkt_ip = IP(dst=ip)
>>> 	sr(pkt_ip/pkt_tcp)
```

Neste caso, criamos um script simples que faz uma varredura nas portas `21`, `22`, `80` e `443` em três IPs diferentes definidos na lista `ips`.

Podemos, também, escrever scripts em python utilizando a biblioteca `scapy`:

```python
# script.py
from scapy.all import *

ips = ["192.168.0.50", "172.16.1.20", "1.1.1.1"]
pkt_tcp = TCP(dport=[21, 22, 80, 443])
for ip in ips:
	pkt_ip = IP(dst=ip)
	sr(pkt_ip/pkt_tcp)
```

E executá-lo com:

```shell
$ python3 script.py
```
