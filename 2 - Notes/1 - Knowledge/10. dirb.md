Ferramenta para fazer brute force em um site para identificar páginas e arquivos. Exemplo de uso:

```shell
$ dirb [site] [wordlist_path]
```

> [!redteam] Mude o User-Agent
> É possível que alguns servidores web bloqueiem o `User-Agent` utilizado pelo `dirb` para fazer a requisição [[5. HTTP]]. Portanto, é uma boa prática alterar seu valor com a opção `-a "Novo User Agent"`.

> [!info] Scanning de arquivos
> Utilize a opção `-X .ext` para fazer scanning de arquivos com a extensão especificada

# Wordlists

`dirb` espera receber como segundo argumento o caminho de uma wordlist. Por padrão, o `dirb` já possui uma série de wordlists que podem ser encontradas em `/usr/share/dirb/wordlists`.
