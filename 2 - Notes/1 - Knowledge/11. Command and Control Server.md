Um C&C Server (ou 2C Server) é um servidor que receberá acessos aos [[7. Shell|shells]] e, tendo acesso a este servidor, consequentemente você terá acesso ao shell da máquina invadida.

Esse tipo de servidor é útil quando múltiplos operadores (atacantes) precisam ter acesso à máquinas comprometidas, ou quando um atacante deseja evitar expor sua própria máquina se conectando diretamente ao host alvo.
