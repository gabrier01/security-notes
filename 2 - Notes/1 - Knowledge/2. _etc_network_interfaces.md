Arquivo que descreve as interfaces de rede disponíveis e permite a realização de algumas configurações.

> [!info] Reboot necessário após alteração
> Após realizar qualquer alteração nesse arquivo, é necessário ou reiniciar a máquina ou reiniciar as interfaces de rede:
> 
> ```shell
> $ reboot
> #ou
> $ /etc/init.d/networking restart
> ```

# Configurar IP privado estático

Adicionar as linhas no arquivo `/etc/network/interfaces`

```
auto eth0
iface eth0 inet static
address 192.168.0.200
netmask 255.255.255.0
gateway 192.168.0.1
```

No exemplo acima:
- `auto`: indica que a interface de rede `eth0` deve ser ativada automaticamente na inicialização do sistema
- `iface`: define a configuração da interface de rede, portanto `iface eth0 inet static`, configura a interface de rede `eth0` para a família de [[5. IP (Address)|IP]] `inet` (`ipv4`) de forma estática.
- `address`: define o endereço IP estático
- `netmask`: máscara da rede `/24`
- `gateway`: define o endereço do gateway, ou seja, do dispositivo responsável por encaminhar pacotes da máquina para outras redes
