[**Shodan**](https://www.shodan.io/) é um motor de busca que faz varredura na internet e indexa dispositivos expostos. O catálogo deles é capaz de incluir [[5. IP (Address)|endereço IP]], sistemas operacionais, geolocalização, serviços e versões, portas abertas etc.

> [!info] Busca passiva
> Como a própria ferramenta armazena o catálogo, as buscas não geram logs do lado do alvo, dessa forma é possível realizar coleta de informações de forma **passiva**.

## Filtros de busca

Alguns filtros de busca úteis:

- `os`: sistema operacional
- `port`: porta do serviço (ex: `21,22,80`)
- `product`: nome serviço, com base em seu banner 
- `version`: versão de um serviço
- `country`: país
- `city`: cidade
- `http.html`: possua a palavra no conteúdo html da página
- `http.title`: título de uma página na web
- `hostname`: pertença a determinado hostname (ex: `google.com`)
- `has_vuln`: filtra os serviços vulneráveis (ex: `true`, `false`)
- `vuln`: possível filtra por [[7. CVE]]
- `ip`: especifica o endereço IP
- `net`: bloco de rede (ex: `8.8.0.0/16`)
- `asn`: número de um [[5. Autonomous System]]

## CLI & API

O **Shodan** tem uma API que pode ser acessada com facilidade pela ferramenta de linha de comando `shodan`.

```shell
shodan init <api-key>
```

Mais informações: https://cli.shodan.io/
