Este comando é uma ferramenta low level para criação de usuários.

```shell
$ sudo useradd -d /home/username -m -s /usr/bin/zsh username
```

> [!info] `adduser`
> Para uma interface de mais alto nível é o comando, ver [[1. adduser]].

O comando acima especifica o diretório **home** do usuário (`-d /home/username)`, especifica que o diretório home deve ser criado (`-m`) e especifica o tipo de shell que o usuário terá acesso ao fazer login (`-s /usr/bin/zsh`). No fim, é especificado o username `username`.

Por padrão, o usuário é criado sem senha, a não ser que seja informado a opção `--password <ENCRYPTED_PASSWORD>`. Contudo, uma forma simples de fazer isso é usando o [[1. passwd]] após a criação do usuário:

```shell
$ passwd username  
```

Depois é possível logar normalmente com o usuário, inclusive em terminais não-root:

```shell
$ su test
```

# Adicionando usuário à um grupo

Isso pode ser feito posteriormente usando o comando `adduser` ([[1. adduser#Adicionando usuário à um grupo|Adicionando usuário à um grupo]]), ou especificando a opção `-G group1,group2,group3`

```shell
$ sudo useradd -d /home/username -m -s /usr/bin/zsh -G group1,group2,sudo username
```

Para remover o usuário de um grupo, veja [[1. deluser#Removendo usuário de um grupo|Removendo usuário de um grupo]]
