Ferramenta para exibir e manipular roteamento, dispositivos de rede, interfaces de rede e tunelamento. Este comando pode substituir por completo o [[1. route]] e [[1. ifconfig]].

# Listar Interfaces de Rede

Exibe as interfaces de rede bem como os [[IP]]s do [[5. Host]], máscara de rede, broadcast etc.

```shell
$ ip addr
```

# Listar rotas

```shell
$ ip route
```
