Utilitário para visualizar a tabela ARP salva no host. Para mais detalhes sobre o protocolo, ver [[5. ARP (Protocol)]]

```shell
# linux
$ arp

# windows
> arp -a
```

> [!redteam]
> Este protocolo é extremamente importante para conectar um host com sua LAN ou WAN. Dessa forma, é improvável que pacotes do protocolo ARP sejam bloqueados por alguma regra de [[5. Firewall]]. Isso pode ser útil para descobrir hosts numa rede sem ser através do [[5. ICMP]], desde que você esteja conectado nesta rede.
