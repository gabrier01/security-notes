É um arquivo de configuração de sistemas [[Windows]] que guarda registros de todos os discos rígidos, partições, drivers etc que já foram conectados no computador, informações sobre caminhos e diretórios do sistema, configurações de hostname, chaves de criptografia etc. O arquivo original comumente fica em `%SystemRoot%\System32\config\SYSTEM`.


> [!NOTE] Title
> É essencial para descriptografar as senhas de usuários contidas no arquivo [[2. SAM]], e ter acesso ao hash limpo.


# Proteção

Assim como o [[2. SAM]], o acesso ao `SYSTEM` é exclusivo do Sistema Operacional e é bloqueado para leitura, escrita ou cópia. Qualquer tentativa de manipular o arquivo original alegará que ele está em uso por outro processo.

# Burlando bloqueio

Há algumas formas de burlar o bloqueio imposto pelo sistema, sendo elas:
- **Acessar o dispositivo fisicamente:** é possível fazer boot com Live CD, acessar o sistema de arquivos sem carregar o windows e acessar o arquivo.
- **Acessar backup em `rapair`**: em sistemas mais antigos é possível acessar backups deste arquivo nos diretórios de [[2. repair]].
- **Recuperar dos registros do windows**: quando o Windows inicializa, o SYSTEM é armazenado em um registry do sistema para acesso mais rápido. Com o comando [[11. reg]] é possível ler o conteúdo desses registries e salvá-los num arquivo. (`reg save HKLM\SYSTEM SYSTEM.bak`)
- **Montar uma cópia sombra ([[VSS]])**: tecnologia do Windows que permite criar snapshots consistentes de volumes em um ponto no tempo, possibilitando a cópia de arquivos mesmo enquanto estão em uso por outros processos.
