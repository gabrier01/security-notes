Ferramenta do conjunto Impacket para extrair credenciais de máquinas Windows. Puxa hashes de contas locais, segredos do LSA, credenciais de domínio em cache e todos os hashes do domínio a partir do [[2. NTDS.dit]]. Funciona tanto remoto pela rede quanto offline (em arquivos de hive já copiados).

> [!NOTE] Nome do comando
> No Kali o binário se chama `impacket-secretsdump`. O nome original do script é `secretsdump.py`. Os dois são a mesma coisa.

```shell
$ impacket-secretsdump [options] [domain/]username[:passwd]@[target]
```

- `[target]`: IP ou hostname do host. Use a palavra `LOCAL` no lugar do alvo para trabalhar em arquivos offline
- `[domain]`: só é necessário em contas de domínio (ver [[8. Active Directory]]).

# Autenticação

As formas de autenticação são as mesmas do [[11. nxc]]:

```shell
$ impacket-secretsdump [domain/]username:passwd@[target] # usuário e senha
$ impacket-secretsdump username@[target] -hashes LM:NT   # Pass-the-Hash
$ impacket-secretsdump [domain/]username@[target] -k -no-pass  # ticket Kerberos
```

> [!warning] Precisa de admin local
> O dump remoto lê o registro e as hives da máquina alvo pelos compartilhamentos administrativos (ver [[14. Compartilhamento Administrativo]]). Isso exige uma conta com privilégio de **administrador local** no host. Sem isso, o dump falha.

# Dump remoto

Contra um host vivo com admin local, o secretsdump lê tudo pela rede e devolve:

- **SAM**: hashes NT/LM das contas locais (ver [[2. SAM]])
- **LSA secrets**: senhas de serviços, conta de máquina, credencial de autologon
- **Cached domain credentials**: as últimas contas de domínio que logaram naquela máquina

```shell
$ impacket-secretsdump CORP/administrador:senha@10.0.0.5
```

> [!redteam] O que fazer com o resultado
> Os hashes NT podem ser usados em técnicas de Pass-the-Hash ou para quebra ([[11. john]], [[11. hashcat]] etc). Já as credenciais de domínio em cache vêm no formato `mscash2` (também conhecido como `DDC2 - Domain Cached Credentials v2`), que só dá para quebrar offline.

# DCSync (domínio inteiro)

DCSync é uma técnica de roubo de credenciais no Active Directory: o atacante abusa do protocolo legítimo de replicação **Directory Replication Service Remote Protocol** (MS-DRSR) para pedir a um Domain Controller que replique dados de contas, como se fosse outro DC. Usando uma conta com direito de replicação (em geral Domain Admin), o secretsdump faz exatamente isso e extrai todos os hashes do domínio direto do [[2. NTDS.dit]], sem copiar nem tocar no disco do DC.

```shell
$ impacket-secretsdump corp/admin:password@dc-ip -just-dc # todos os hashes + chaves kerberos
$ impacket-secretsdump corp/admin:password@dc-ip -just-dc-ntlm # só NTLM
$ impacket-secretsdump corp/admin:password@dc-ip -just-dc-user krbtgt # uma conta só
```

> [!tip] Alvos valiosos
> `-just-dc-user krbtgt` pega o hash da conta `krbtgt`, que é requisito para gerar um [[11. Golden Ticket]].

> [!tip] Parâmetros úteis
> - `-history` inclui os hashes de senhas antigas, importante quando o alvo recicla senhas.
> - `-outputfile creds` salva a saída em arquivos ao invés de jogar tudo em stdout.

# Dump offline

Quando você já tem as hives ou o NTDS.dit copiados (por exemplo via `reg save` ou cópia por VSS, ver [[2. NTDS.dit#Burlando bloqueio|NTDS.dit - Burlando bloqueio]]), roda tudo local passando a palavra `LOCAL` no fim:

```shell
# contas locais, a partir das hives do registro
$ impacket-secretsdump -sam sam.save -system system.save -security security.save LOCAL

# base do domínio inteiro
$ impacket-secretsdump -ntds ntds.dit -system system.save LOCAL
```

> [!tip] Vantagem sobre o samdump2
> É a alternativa ao [[11. samdump2]] para o SAM, e ainda processa o NTDS.dit, coisa que o samdump2 não faz.

# Lendo a saída

Cada linha de hash NTLM vem neste formato:

```
domain\username:rid:lmhash:nthash:::
```

- o campo que interessa para Pass-the-Hash e para quebra é o `nthash`.
- o `lmhash` costuma vir vazio (`aad3b435b51404eeaad3b435b51404ee`) em sistemas modernos, indicando que `LM` está desativado.
- os segredos do LSA e as credenciais em cache saem em blocos separados, alguns já em texto claro
