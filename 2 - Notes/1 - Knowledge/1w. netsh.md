Utilitário de linha de comando para configurar dispositivos e conexões de rede. Em pentest é muito utilizado para modificar regras de firewall

#todo

```powershell
> netsh advfirewall firewall add rule name=<rule-name> protocol=<protocol> dir=<direction(in/out)> localport=<port> action=<(allow/disallow)>
```
