Ferramenta utilizada para escrever e ler [[6. Files Metadata|metadados]] de um arquivo. Essa ferramenta pode ser utilizada para garimpar informações sobre um alvo e expor sistema operacional, software (e versão) usado para a criação do arquivo etc.

```shell
$ exiftool file.pdf 
```
