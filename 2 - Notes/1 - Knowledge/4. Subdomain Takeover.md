O **Subdomain Takeover** explora uma vulnerabilidade de registros `CNAME` que apontam para um domínio não registrado. Por exemplo:

```
sub.company.com CNAME unregistered.domain.com
```

Se alguém registrar o domínio `unregistered.domain.com`, fará com que qualquer acesso à `sub.company.com` seja redirecionado para o domínio recém registrado. Esse tipo de vulnerabilidade pode ser explorada para ataques de [[7. Engenharia Social]], criando páginas falsas que utilizem domínios reais de um alvo.

> [!redteam] Identificando CNAMEs para domínios não registrados #redteam 
> É possível identificar se um domínio possui uma entrada **CNAME** fazendo a seguinte consulta abaixo:
> 
> ```shell
> $ dig +short CNAME domain.com 	
> ```
>Se retornar alguma coisa, significa que este sub domínio possui uma entrada **CNAME** no Zone File; a partir daí é preciso verificar se o domínio retornado está registrado e isso pode ser feito com o [[1. whois]]:
>```shell
>$ whois other.domain.com
>```
>
Veja [[6. Enumerar Subdomínios]] para saber como descobrir subdomínios de um alvo.

> [!blueteam] Como se proteger #blueteam 
> Remova qualquer registro **CNAME** de um [[5. Zone File]] que aponte para domínios não registrados. Caso seja necessário manter o registro, certifique-se de ao menos registrar o domínio, mesmo que não esteja sendo utilizado.
