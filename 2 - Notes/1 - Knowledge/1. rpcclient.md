Cliente de linha de comando que faz parte do [[8. samba]] para interagir com serviços [[5. SMB]], especificamente para interagir com o host remoto via **Remote Procedure Calls (RPC)**.

# Conexão

Para se conectar, basta executar o comando abaixo:

```shell
$ rpcclient -U "[username]" //[IP ou HOSTNAME]
# As "aspas" são importantes para o -U
```

O que ele faz é se conectar ao share `IPC$` que por sua vez abre [[7. Named Pipe|named pipes]] pra que o cliente execute procedimentos via [[5. RPC]]. Após a conexão, um shell interativo é aberto, permitindo a execução de [[#Comandos|comandos]].

# Named Pipes SMB

Como dito anteriormente, cada named pipe é uma interface para a realização de operações diferentes. As principais named pipes podem ser encontradas em [[5. SMB#IPC e Named Pipes|IPC e Named Pipes]].

A maioria dos comandos suportados pelo `rpcclient` abstraem a named pipe, dessa forma nem sempre é preciso especificá-la.

# Comandos

Com uma conexão estabelecida, é possível enviar comandos pelo shell interativo do `rpcclient`. Para detalhes sobre todos os comandos suportados pelo cliente, bastar enviar `help` no shell interativo. Exemplo de comandos interessantes:

## `SrvInfo`

Envia uma mensagem para a pipe `\pipe\srvsvc` para mostrar informações do servidor SMB, como nome do serviço, versão, configurações específicas etc.

```
rpcclient $> SrvInfo
```

> [!redteam] Identificar vulnerabilidades
> Com o nome do serviço, sua versão e possíveis configurações é possível refinar o processo de identificação de vulnerabilidades, especialmente se o serviço possuir uma CVE.

## `NetShareEnum`

Envia uma mensagem para a pipe `\pipe\srvsvc` para listar apenas os compartilhamentos visíveis ao usuário.

```shell
rpcclient $> NetShareEnum
```

## `NetShareEnumAll`

Envia uma mensagem para a pipe `\pipe\srvsvc` para enumerar todos os compartilhamentos do host.

```shell
rpcclient $> NetShareEnumAll
```

> [!redteam] Enumeração recursos
> Útil para enumerar todos os compartilhamentos, identificar recursos públicos, administrativos ou ocultos. 

## `NetShareGetInfo`

Envia uma mensagem para a pipe `\pipe\srvsvc` para obter informações detalhadas de um recurso compartilhado.

```shell
rpcclient $> NetShareGetInfo [sharename] 
```

> [!redteam] Verificar permissões
> Com este comando é possível verificar as permissões de acesso a um recurso, ou seja, se é possível visualizar, escrever, deletar etc.

## `EnumDomUsers`

Envia uma mensagem para a pipe `\pipe\samr` para listar usuários locais e do domínio.

```shell
rpcclient $> EnumDomUsers
```

> [!redteam] Enumeração de usuários
> Útil para enumerar usuários e identificar contas para bruteforce ou ataques de credenciais.

## `QueryUser`

Envia uma mensagem para a pipe `\pipe\samr` para exibir informações detalhadas sobre um usuário.

```shell
rpcclient $> QueryUser [username]
```

> [!redteam] Detalhes de usuário
> Útil para obter detalhes de usuários, como último login, status etc para reconhecimento aprofundado.

## `GetDomPwInfo`

Envia uma mensagem para a pipe `\pipe\lsarpc` para obter informações sobre a política de senhas do domínio.

```shell
rpcclient $> GetDomPwInfo
```

> [!redteam] Planejar bruteforce
> Saber o comprimento mínimo da senha, complexidade exigida (uso de símbolos, números etc), tempo máximo e mínimo para alteração de senha, histórico de senhas proibidas, bloqueio de conta e duração do bloqueio etc são informações úteis para planejar um ataque de bruteforce.
