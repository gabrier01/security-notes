Cliente de linha de comando do [[8. samba]] para conversar com serviços [[5. SMB]] via **Remote Procedure Calls (RPC)**. Serve principalmente para enumerar o host remoto: usuários, grupos, compartilhamentos e política de senhas.

# Conexão

```shell
$ rpcclient -U "[usuário]" //[IP ou HOSTNAME]
# as aspas no -U importam
```

Ele se conecta ao share `IPC$`, que abre [[14. Named Pipe|named pipes]] para executar procedimentos via [[5. RPC]]. Depois de conectado, abre um shell interativo onde você roda os [[#Comandos|comandos]].

> [!tip] Sessão nula (anônima)
> Vários servidores deixam enumerar sem senha. Sempre vale testar uma sessão nula antes de ter credenciais:
> ```shell
> $ rpcclient -U "" -N //[IP]
> # -N não pergunta senha; -U "" usa usuário vazio
> ```

> [!tip] Rodar sem entrar no shell
> Com `-c` você executa o comando direto e já sai. Bom para automatizar ou juntar tudo numa linha só:
> ```shell
> $ rpcclient -U "" -N -c "enumdomusers" [IP]
> $ rpcclient -U "" -N -c "srvinfo; enumdomusers; getdompwinfo" [IP]
> # separe vários comandos com ;
> ```

# Named Pipes

Cada named pipe é uma interface para um conjunto de operações. As principais estão em [[5. SMB#IPC e Named Pipes|IPC e Named Pipes]]. A maioria dos comandos do `rpcclient` já abstrai a pipe, então quase nunca você precisa informá-la.

# Comandos

Conectado, mande `help` para ver todos os comandos. Eles não diferenciam maiúsculas de minúsculas (`srvinfo` funciona igual a `SrvInfo`). Abaixo os mais úteis.

## `srvinfo`

Mostra dados do servidor SMB: nome, versão e configurações. Pipe `srvsvc`.

```
rpcclient $> srvinfo
```

> [!redteam] Identificar vulnerabilidades
> Com nome e versão do serviço dá para refinar a busca por vulnerabilidades, principalmente se existir uma CVE conhecida.

## `netshareenum` e `netshareenumall`

`netshareenum` lista os compartilhamentos visíveis ao usuário. `netshareenumall` lista todos, inclusive administrativos e ocultos. Pipe `srvsvc`.

```
rpcclient $> netshareenumall
```

> [!redteam] Enumerar recursos
> Bom para achar compartilhamentos públicos, administrativos ou escondidos.

## `netsharegetinfo`

Detalha um compartilhamento específico, incluindo permissões. Pipe `srvsvc`.

```
rpcclient $> netsharegetinfo [share]
```

> [!redteam] Verificar permissões
> Mostra se você consegue ler, escrever ou apagar no recurso.

## `enumdomusers`

Lista usuários, locais ou do domínio dependendo do host. Retorna o nome e o `rid` de cada conta. Pipe `samr`.

```
rpcclient $> enumdomusers
```

> [!redteam] Enumeração de usuários
> Gera a lista de contas alvo para spraying ou bruteforce. O `rid` serve de entrada para o `queryuser`.

## `queryuser`

Detalha um usuário pelo `rid`: último login, status da conta e flags. Pipe `samr`.

```
rpcclient $> queryuser [rid]
```

## `enumdomgroups`

Lista os grupos do domínio, revelando parte da estrutura da organização. Pipe `samr`.

```
rpcclient $> enumdomgroups
```

> [!redteam] Achar administradores
> Anote o `rid` dos grupos de administração e use `querygroupmem` para ver quem está dentro.

## `querygroup`

Mostra informações de um grupo pelo `rid`, incluindo a quantidade de membros. Pipe `samr`.

```
rpcclient $> querygroup [rid]
```

## `querygroupmem`

Lista os `rid` dos membros de um grupo. Pipe `samr`.

```
rpcclient $> querygroupmem [rid]
```

> [!tip] Do grupo ao usuário
> `querygroupmem` devolve `rid`, não nomes. Passe cada `rid` no `queryuser` para descobrir quem é. Assim você foca esforço só nas contas que importam, como os membros de Domain Admins.

## `getdompwinfo`

Mostra a política de senhas do domínio. Pipe `lsarpc`.

```
rpcclient $> getdompwinfo
```

> [!redteam] Planejar bruteforce
> Saber comprimento mínimo, complexidade, bloqueio de conta e duração do bloqueio evita travar contas e ajuda a montar a wordlist certa.

# Dicas extras

> [!tip] RID cycling
> Se `enumdomusers` estiver bloqueado, ainda dá para enumerar contas pelo SID. Pegue o SID do domínio com `lsaquery` e resolva os RIDs um a um:
> ```
> rpcclient $> lookupnames administrator    # nome para SID e rid
> rpcclient $> lookupsids S-1-5-21-...-500   # SID de volta para nome
> ```
> Os RIDs seguem um padrão previsível: 500 é Administrator, 501 é Guest, 512 é Domain Admins.

> [!tip] Trocar a senha de um usuário
> Com permissão suficiente, o `rpcclient` altera a senha de uma conta sem saber a atual:
> ```
> rpcclient $> setuserinfo2 [usuário] 23 [nova_senha]
> ```
> Útil quando você tem direito de reset sobre a conta, mas não conhece a senha original.
