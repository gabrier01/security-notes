O grupo `sudo` (não confundir com o comando [[1. sudo]]) é um grupo em que os usuários pertencentes possuem privilégios elevados que os permitem executar **qualquer ação no sistema**, como um superusuário, sem restrições.

O motivo pelo qual este grupo possui esses privilégios se dá pela configuração do arquivo [[2. _etc_sudoers|/etc/sudoers]], em que a seguinte linha é definida:

```
# Allow members of group sudo to execute any command
%sudo    ALL=(ALL:ALL) ALL
```

Dessa forma, usuários do grupo `sudo` podem executar comandos **com permissões de qualquer usuário e qualquer grupo no sistema**, incluindo o [[root]] e grupos especiais.
