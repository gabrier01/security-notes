Utilitário para parser e formatação de linhas de uma stream.

```shell
$ cut -d ";" -f1,3 log.txt;
# -d: delimitador usado para separar a linha em colunas indexaveis
# -f: índice das colunas(fields) que devem ser retornadas para a saída padrão
```
