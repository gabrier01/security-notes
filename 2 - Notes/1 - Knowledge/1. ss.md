Utilitário para investigar sockets abertos em um host. É um substituto mais moderno e eficiente ao `netstat`.

Exemplo de uso para listar os `sockets` que estão **escutando**, portanto abertos, conexões `tcp`. 

```shell
$ ss -Qltnp

# -Q = omite as linhas de RECV e SEND (enxuga o output)
# -l = listening
# -t = apenas sockets tcp
# -n = exibe o número da porta, ao invés do nome
# -p = exibe o PID do programa que abriu a porta
```

Mais detalhes podem ser obtidos com `man ss`
