É um utilitário usado para verificar conexão com um [[5. Host]] de destino. Por baixo dos panos, o `ping` envia um pacote [[5. ICMP]] com `type=8 (echo request)`. O host de destino então pode responder com um outro pacote `icmp` com `type=0 (echo reply)`, mas também é possível que retorne  `destination port unreachable` ou não retorne nada.

```shell
ping -c1 [host]
# -c <number>: quantidade de pacotes para serem enviados
```
