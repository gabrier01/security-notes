O comando `sudo` (não confundir com o grupo [[3. sudo (group)]]) é um binário que permite um usuário regular elevar seus privilégios e executar ações com permissões de outro usuário e grupo. Para que isso seja possível, o usuário deve pertencer ao grupo [[3. sudo (group)]].

O modo mais comum de se utilizar o `sudo` é para executar comandos com permissões de superusuário, ou seja, [[root]].

O comportamento do comando `sudo` pode ser configurado especificamente para cada usuário e grupo através do arquivo [[2. _etc_sudoers|/etc/sudoers]].
# Exemplos:

1. Modo tradicional de uso, em que é comando é executado como `root`:
   
```shell
$ sudo cat /etc/sudoers 

# mesma coisa que:

$ sudo -u root -g root cat /etc/sudoers
```

2. Outro modo de uso, em que o comando é executado com permissões de outro usuário. Com isso, um usuário `username` consegue elevar privilégios e se passar pelo usuário `gabrier`, acessando tudo que `gabrier` pode acessar:
   
```shell
$ sudo -u gabrier ls /home/gabrier/Desktop
```

3. Outro modo de uso, em que o comando é executado com permissões de outro grupo. Com isso, um usuário `username` consegue elevar privilégios e se passar como se fizesse parte do grupo `example`, mesmo que não faça, podendo acessar tudo que qualquer usuário desse grupo tem acesso:

```shell
$ sudo -g example ls /exclusive/example
```
