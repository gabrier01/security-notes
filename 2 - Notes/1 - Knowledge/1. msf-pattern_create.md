Ferramenta do [[1. msfconsole|Metasploit]] que gera uma string de padrão único (não repetitivo) de um tamanho definido. Serve pra descobrir o offset exato até o endereço de retorno num [[4. Buffer Overflow]]: em vez de mandar só `A`, você manda esse padrão e, quando o programa trava, cada trecho da string é identificável, então dá pra saber que parte dela caiu no registrador `EIP`.

O valor que caiu no `EIP` você joga no [[1. msf-pattern_offset]] pra converter em offset.

# Uso

```shell
$ msf-pattern_create -l [tamanho]         # tamanho em bytes do padrão
$ msf-pattern_create -l 1200
```

- `[tamanho]`: quantidade de bytes do padrão, use um valor um pouco maior que o buffer que causou o crash

> [!note] Nome do binário
> No Kali o wrapper é `msf-pattern_create` (com hífen). O script original é o `pattern_create.rb`, em `/usr/share/metasploit-framework/tools/exploit/`.

> [!tip] Use o mesmo `-l` nas duas etapas
> O `[tamanho]` passado aqui tem que ser o mesmo usado no [[1. msf-pattern_offset]], senão o offset calculado sai errado.
