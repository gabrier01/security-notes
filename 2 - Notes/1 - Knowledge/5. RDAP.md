**Registration Data Access Protocol (RDAP)** é um protocolo, similar ao [[5. WHOIS (Protocol)]], específico para consultar informações de contato e [[5. DNS (Protocol)]] sobre um domínio, endereço IP ou [[7. ASN]]. Dentre as melhorias estão: padronização do formato de consultas e respostas, suporte a internacionalização e autenticação.

O protocolo foi construído em cima do [[5. HTTP]], portanto segue o mesmo padrão de cabeçalho e payload.

A maioria dos registradores, [[5. IANA#RIR|RIRs]] etc já implementam este protocolo ou está em processo de implementação.

# Request

Request para busca de informações de um domínio:

```http
GET /domain/itau.com.br HTTP/1.1
Host: rdap.arin.net
User-Agent: ...
Accept: application/rdap+json
Authorization: ...
```

- `Authorization` na maioria das vezes é opcional, contudo há implementações que vão exigir.
- É recomendado que informe um `User-Agent`.
- O path poderia ser `/ip/192.168.0.1`, para buscar por um [[5. IP (Address)]]


> [!NOTE] Domain **Vs** IP
> Assim como no **WHOIS**, há uma diferença entre busca por domínio e busca por IP. Buscar o domínio irá trazer informações como nome do dono, empresa responsável pela venda do domínio, status etc. Buscar por IP traz informações como [[5. IANA#Net Number|net number]], [[5. IANA#ASN|ASN]] (opcional), empresa que controla o range de IP, contatos técnicos etc.

# Response

Response de uma requisição RDAP:

```json
{
    "objectClassName": "domain",
    "handle": "itau.com.br",
    "ldhName": "itau.com.br",
    "nameservers": [
        {
            "objectClassName": "nameserver",
            "ldhName": "usw1.akam.net",
            "events": [
                ...
            ]
        },
        ...
    ],
    "links": [
        {
            "value": "https://rdap.registro.br/domain/itau.com.br",
            "rel": "self",
            "href": "https://rdap.registro.br/domain/itau.com.br",
            "type": "application/rdap+json"
        }
    ],
    "status": ["active"],
    "rdapConformance": [
        "rdap_level_0",
        "nicbr_level_0"
    ],
    "port43": "whois.registro.br",
    ...
}
```


O payload acima é um `json` bem extenso e teve partes removidas. Mas os campos importantes são:
- `objectClassName`: tipo do objeto (`domain`, `ip network`, `autnum`)
- `handle`: identificador único do recurso
- `startAddress` / `endAddress`: intervalo IP
- `entities`: contatos e orgs relacionadas
- `events`: datas (criação, modificação etc.)
- `links`: URLs úteis (ex: recurso direto, documentação)


> [!tip] Client para consultas
> `client.rdap.org` pode ser usado para fazer consultas **RDAP**.
