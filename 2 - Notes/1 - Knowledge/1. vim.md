`vim` é um editor de texto para sistemas unix.

# Modo Normal

É o modo de execução de comandos. Neste modo, você pode especificar uma combinação de letras para executar um comando
- `:w` "write", salva o conteúdo
- `:q` fecha o vim. Adicione `!` ao final para forçar a saída sem salvar (`:q!`).
- `yy` copia a linha do cursor
- `p` cola a linha copiada com `yy`
- `dd` deleta a linha do cursor
- `.` refaz o último comando realizado
- `u` desfaz a última ação
- `:%s/jonh/john/g` realiza substituição de todas as ocorrências (`/g`) do texto `jonh` por `john` no arquivo inteiro (`%`). Ao combinar `/gn` é realizado apenas uma contagem de ocorrências de `jonh`.
- `/palavra` vai até a próxima ocorrência de `"palavra"` 

Para entrar no modo normal, bastar apertar a tecla `esc`

# Modo de Edição

Dentro do **modo normal**, digite `i` para entrar no **modo de edição**. Neste modo você pode digitar texto.
