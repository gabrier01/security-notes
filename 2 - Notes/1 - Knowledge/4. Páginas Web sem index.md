Alguns servidores [[5. HTTP]], dependendo da forma como são configurados, simplesmente mapeiam um `path` na URL de um site para um caminho no sistema de arquivos do servidor. Por exemplo, num servidor `apache`, rodando num `Linux`, ao acessar `example.com/path/to/page` o caminho `path/to/page` será mapeado para o diretório `var/www/html/path/to/path`.

É aconselhável que o diretório contenha um arquivo `index.html` para que este seja renderizado quando um cliente requisitar o `path`, pois se isso não for feito, ocorrerá uma listagem de todos os arquivos do diretório e, dependendo da ocasião, poderá expor arquivos sensíveis.

> [!redteam] Buscar páginas sem index #redteam
> É possível utilizar de [[6. Google Hacking]] para buscar com facilidade páginas sem index, basta apenas fazer uma busca com a seguinte dork:
> ```
> intitle:"index of"
> ```

> [!blueteam] Evitar listagem de diretório #blueteam
> A forma mais simples é incluir um `index.html` no diretório. Contudo, há outras opções dependendo do servidor. No `apache`, por exemplo, é possível configurar o arquivo `httpd.conf`; há servidores como `nginx` e `IIS` que desabilita por padrão a listagem de diretórios em seus arquivos de configuração.
