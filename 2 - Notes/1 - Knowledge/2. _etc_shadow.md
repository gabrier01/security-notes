É um arquivo usado para armazenar as senhas dos usuários criptografadas no Linux, além de informações sobre datas de expiração e validade das contas.

```shell
$ cat /etc/passwd
# root:x:0:0:root:/root:/usr/bin/zsh
# daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
# bin:x:2:2:bin:/bin:/usr/sbin/nologin
```
