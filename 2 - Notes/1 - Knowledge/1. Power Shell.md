Powershell é a linguagem de script utilizada em sistemas Windows atuais.

* **Listar todos os comandos do powershell:**
```powershell
Get-Command  
```

* **Criação de variáveis**
```powershell
$ip = "192.168.0.1"
$port = Read-Host "Informe a porta" 

echo "Ip: $ip"
echo "Port: $port"
echo "Socker: ${ip}:${port}" # ${} is used to avoid interpret ':' as part of the variable name 
```

- **Condicionais:**
```powershell
$ip = "192.168.0.1"
$port = Read-Host "Informe a porta" # or `[int]$port = ...` to cast the value to integer 

if([int]$port -lt 0) { # in order to compare $port with a number, we must convert it to integer
	echo "Invalid port: $port is less than 0"
} elseif([int]$port -gt 65535) {
	echo "Invalid port: $port is greater than 65535"
} else {
	echo "OK: valid value ${ip}:${port}"
}
```

- **Argumentos do script:**
```powershell
param($filename, $string)

# the condition below could be: if(!$filename -or !$string)
if($filename -eq $null -or $string -eq $null) {
	echo "Usage: ./script.ps1 filename string-to-find"
	exit
}


Get-Content $filename | Select-String $string
```

* **Repetições:**
```powershell
param($network)
if(!$network) {
	echo "Usage: ./script.ps1 partial-network"
	echo "   Example: ./script.ps1 192.168.0"
	exit
}

foreach ($i in 1..254) {
	$match = ping -n 1 "$network.$i" | Select-String "bytes=32"
	if(!$match) {
        continue
    }
    
    echo $match.Line.split(" ")[2]
    # $match is the Select-String result. .Line is to access the match, which is a string. .split is a string method.
}
```

* **Criar lista:**
```powershell
[int[]]$ports = 21, 22, 80, 443, 3306

foreach($port in $ports) {
	echo "Scanning port $port"
}

# -----
$namesInput = Read-Host "Nomes (separados por vírgula)"
[string[]]$names = $namesInput.split(",")

foreach($name in $names) {
	echo "Name: $($name.trim())"
}
```
