Ferramenta para coleta de informações públicas sobre um alvo. Utiliza de vários meios de busca para a coleta.

```shell
$ theHarvester -d exemple.com -l limit -b where-to-collect -f harvested_data.html
```


> [!warning] Google
> As versões mais recentes perderam suporte a buscas pelo `google`.

# O que busca:

Dependendo do modo de uso, o `theHarvester` pode buscar por:
- **emails**
- **portas abertas**
- **domínios**
- **IPs**

# Configurações

## API Keys

Algumas buscas que o `theHarvester` faz envolve uso de APIs. Para que funcione corretamente é necessário configurar as apis no arquivo `/etc/theHarvester/api-keys.yaml`, no seguinte formato:

```yaml
apikeys:
	github:
		key: <value>
	shodan:
		key: <value>
	<source>:
		key: <value>
```

## Proxy

É possível também configurar proxy para que o `theHarvester` faça as buscas. Isso pode evitar alguns bloqueios por IP. A configuração deve ser feita no arquivo `/etc/theHarvester/proxies.yaml`
