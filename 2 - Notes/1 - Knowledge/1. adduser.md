É um utilitário responsável por criar ou manipular users de um sistema. Basicamente é um "frontend" mais amigável para o comando [[1. useradd]]. A forma mais convencional do `adduser` é para criar um usuário regular (non-system user):

```shell
$ adduser [username]
```

Ao fazer isso, será criado um usuário com o nome `username` e uma pasta `username` em `/home` com arquivos pré-configurados. Também será solicitado a senha para este usuário, a não ser que a opção `--disabled-password` seja informada.

Além disso, um grupo com o mesmo é criado para ser o grupo primário deste usuário. Isso segue o modelo **User Private Group (UPG)**, que adiciona uma camada de isolamento entre os usuários do sistema. Nesse modelo, arquivos e diretórios criados pelo usuário `x` pertencem, por padrão, ao grupo `x`, e somente quem faz parte desse grupo terá permissões de grupo sobre esses arquivos.

Este comando possui opções mais avançadas como: criar usuários de sistema (system users), criar grupos, adicionar usuários a grupos etc. Essas opções podem ser verificadas com `man adduser`.

## Adicionando usuário à um grupo

Outra funcionalidade do `adduser` é de adicionar um usuário à um grupo. Isso pode ser feito da seguinte forma:

```shell
$ adduser [username] [group]
```

Isso é útil, por exemplo, para adicionar o usuário `username` ao grupo [[3. sudo (group)]] após sua criação, permitindo que o usuário recém criado possa executar comandos com privilégios de [[root]].

Para remover o usuário de um grupo, veja [[1. deluser#Removendo usuário de um grupo|1. deluser - Removendo usuário de um grupo]]
